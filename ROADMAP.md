# Моя вулиця — ROADMAP до повного запуску

Статус: головний план реалізації
Оновлено: 2026-09-11

Цей файл є робочим маршрутом від поточного стану репозиторію до повністю запущеного consumer-продукту «Моя вулиця» з історичними даними, автоматичними оновленнями, FREE, PRO, оплатою, SEO, моніторингом і перевіреною бізнес-моделлю.

## Зафіксовані продуктові рішення

- Продукт: інтерактивна карта правопорушень та проблемних зон міста.
- Судові рішення — джерело; продукт показує реконструйовані події.
- UX за зумом: місто → hex-соти → проблемні зони → адреси/події → фабула.
- Немає перемикача «Події / Проблеми».
- FREE показує, що відбувалося; PRO допомагає зрозуміти закономірності.
- AI-фабула FREE; No source → no fact.
- Немає safety score, «небезпечних будинків», predictive policing або причинних тверджень без доказів.
- MVP-географія: Київ. Архітектура одразу багатоміська.
- Після стабілізації Києва: великі міста → вся Україна.
- Кінцева історична база: всі доступні роки ЄДРСР, для яких можна забезпечити прийнятну якість.
- FREE-карта без обов'язкової реєстрації. Акаунт потрібен для PRO/платежів і майбутніх персональних функцій.
- Production storage: PostgreSQL + PostGIS; raw snapshot-и ЄДРСР зберігаються окремо від Git.
- Карта читає API, а не ZIP/CSV напряму.

# Definition of DONE для всього проєкту v1

Проєкт не вважається завершеним лише тому, що «карта відкривається».

V1 вважається повністю реалізованою, коли:

- [ ] офіційні дані ЄДРСР системно оновлюються без ручної роботи;
- [ ] усі придатні доступні історичні роки завантажені;
- [ ] документ, справа, подія та локація не змішуються;
- [ ] дедуплікація не множить одну реальну подію через кілька рішень;
- [ ] на карту не потрапляє адреса суду/проживання замість місця події;
- [ ] AI-фабули мають source provenance та factuality QA;
- [ ] hex/problem methodology відтворювана;
- [ ] карта реалізує узгоджений zoom UX;
- [ ] FREE є повноцінним продуктом;
- [ ] PRO дає динаміку, аналіз, порівняння та контекст;
- [ ] акаунти й рекурентна оплата працюють у production;
- [ ] API, БД, backups, monitoring і weekly pipeline працюють у production;
- [ ] legal/privacy gate пройдено;
- [ ] SEO/share/acquisition працюють;
- [ ] product analytics вимірює основну воронку;
- [ ] Київ запущено публічно;
- [ ] система готова/почала масштабування на інші міста;
- [ ] отримані реальні дані про FREE→PRO конверсію та готовність платити.

# Як працюємо за ROADMAP

1. Беремо найближчий незакритий блок, залежності якого вже виконані.
2. Технічні рішення, що не змінюють продукт, реалізуються без повторного погодження фундаменту.
3. Продуктові, юридичні, цінові або методологічні рішення з істотним впливом виносяться Андрію на контрольну точку.
4. Зміни: branch → code/tests → PR → green CI → merge.
5. Після завершення значущого пункту оновлюємо цей ROADMAP.
6. Не ставимо `[x]` за сам факт написання коду: пункт закритий лише після перевірки його критерію.
