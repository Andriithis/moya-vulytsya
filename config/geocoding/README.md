# Початкові географічні довідники Києва

Дані не містять подій, судових текстів або приватних адрес із рішень.

- `kyiv_boundary.geojson`: похідна геометрія OpenStreetMap relation 421866.
  © OpenStreetMap contributors; ODbL 1.0. [Умови й attribution](https://www.openstreetmap.org/copyright).
  Джерело, версія та SHA-256 містяться у properties.
- `street_aliases.json`: 4 пари назв і 3 неоднозначні назви з офіційного
  переліку КМДА. URL, сторінки й SHA-256 PDF в кожному записі.

Обсяг перевірки — джерела та структура, виконавець — асистент.
Незалежний людський QA не виконаний. Не трактувати цей початковий довідник
як повний реєстр історичних адрес чи кадастрову межу.

Методика й обмеження: [звіт](../../docs/phase2-reference-validation.md).
