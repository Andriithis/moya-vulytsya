### Один файл замість одинадцяти — зроблено

Районних карт як окремих файлів більше немає. Карта міста несе межі всіх
десяти районів і **власний перелік проблем для кожного**. Клік по району:
карта плавно під'їжджає (`flyToBounds`), решта міста затемнюється маскою,
бічна панель перемикається на район — заголовок, лічильники статей, «Топ
адрес», підпис про склад проблем. Вихід — «← усе місто».

**Фільтри при переході більше не скидаються** — раніше вони гинули разом
із перезавантаженням сторінки.

Адреса виду `kyiv.html#desna` відкриває район одразу: плитки оглядової
сторінки ведуть саме туди, і викладач може дати групі посилання на
конкретний район.

**Районні переліки.** Поріг той самий — `MIN_EPISODES = 15`, визначення
проблеми не пом'якшувалося. Береться до `DISTRICT_TOP = 10` найгостріших
у межах району, з квотою за темами. Разом 95: по десять скрізь, крім
Деснянського (7) і Дніпровського (8) — там стільки місць долає поріг,
і це теж відповідь, а не хиба.

**Вага.** Було 11 файлів на 10,3 МБ у кожній версії, стало один на 4,3 МБ.
Проблеми всіх одинадцяти переліків важать 40 КБ — уся вага в потоках.
Наступний крок там: геометрія відрізка зараз записана тричі, по разу на
шар; якщо записати один раз і додати три масиви значень, усі 6 774
відрізки займуть 1,28 МБ замість нинішніх 1,34 МБ за обрізані 2 500.

Що змінилося у файлах: `map_problems.py` (районні переліки, район кожної

## 5. Завдання

### 5.1. Наведення ладу `[головне]`

Не окреме завдання, а режим роботи: пройти карту від початку до кінця, знайти й
виправити все, що заважає. Почато 2 вересня, див. розділ 4.

Після кожної правки — перебудова карти на синтетичному місті, перевірка балансу
тегів і `node --check`. Не покладатися на те, що «має працювати».

### 5.2. Один файл замість одинадцяти

Зараз збираються місто плюс десять районів, окремими файлами по ~12 МБ. Перехід
між ними — перезавантаження сторінки.

**Робимо один файл.** Міська карта вже несе всі дані; районні — підмножини, і
вхід у сайт усе одно через міську. Клік по району: карта переїжджає, фіксується,
затемнює решту.

**І головне — район стає рівнем аналізу, а не окремим файлом.** Переліки проблем
і ризиків перераховуються всередині району зі своїми порогами. Місце з вісьмома
епізодами не тягне на міську проблему, але може бути найгіршим у Деснянському.
Дільничний працює районом, а не містом.

Заразом зникає баг із карткою (розділ 4), бо зникає окрема гілка збірки.

Перед впровадженням — виміряти вагу об'єднаного файлу.

### 5.3. Фабули за посиланням із картки проблеми

Без виїздів **текст рішення — єдине джерело причини**.

`step1_download.py` качає текст, витягує адресу і **текст викидає** — у базі його
немає. Але повний текст доступний за посиланням на реєстр, і `doc_url` у нас є.

**Наполовину вже працює:** у вікні адреси є розділ «Приклади рішень» із
посиланнями. Лишається зробити перелік **для конкретної проблеми** (адреса плюс
механізм), а не для адреси загалом.

### 5.4. Значки замість кружечків

## 6. Правила роботи з репозиторієм

**Запис у GitHub працює.** Через конектор — `mcp__GitHub__push_files` із повним
вмістом файлу. Обговорюємо в чаті, зміни вносяться одразу.

**Про `git push`. Питання закрите: не працює і не запрацює.**
Проксі відповідає «is not in this session's authorized repository set… add the
repository to the session's sources», але **способу додати репозиторій до
джерел сесії в застосунку немає** — ні в конекторах, ні в «Add from GitHub»,
ні в налаштуваннях, ні на екрані створення задачі. Це відомий відкритий баг
`anthropics/claude-code#76248`. Перевірено 2 вересня, часу на це більше не
витрачаємо.

**Що працює замість нього.** `git clone` із пісочниці працює — тому читати
репозиторій треба клонуванням, а не по файлу через конектор. Запис іде двома
шляхами: `mcp__GitHub__push_files` для дрібних правок або запис у папку на
комп'ютері з наступним Commit + Push у GitHub Desktop — другий шлях надійніший,
бо виключає підміну символів.

**Єдиний реальний виняток:** токен не має дозволу `workflow`, тому
`.github/workflows/update.yml` редагує лише користувач вручну. Будь-яке
виправлення конвеєра має вміщатися в `src/`.

**Після кожного push — перевірка.** Символ `і` (U+0456) зрідка перетворюється на
інший схожий. Найпростіше — `PEREVIRKA.bat` на клоні. Або вручну:

```
git clone --depth 1 https://github.com/Andriithis/karta-kyiv.git /tmp/chk
diff локальний_файл /tmp/chk/src/файл
python3 -m py_compile /tmp/chk/src/*.py
```

Для шаблону додатково: витягнути `<script>` зі згенерованої `site/kyiv.html`,
перевірити `node --check`, розмітку — балансом тегів через `HTMLParser`.
Усе це вже робить `PEREVIRKA.bat` — окремо вигадувати не треба.

**Мережа з пісочниці.** `reyestr.court.gov.ua`, `overpass-api.de` та
`api.github.com` через curl недоступні. Працюють WebSearch, WebFetch, конектор
GitHub і `git clone`. Двигун і карту тестуємо на `data/events_test.db.gz` —
зменшеній справжній базі, яка лежить у репозиторії.

**Мова.** Українською. Пункти інтерфейсу називати їхніми українськими підписами.

**Тон.** Коротко й простими словами.

## 7. Журнал рішень

**2 вересня.**

- **Правові назви статей беремо лише з перевірених джерел.** Де надійного
  джерела немає — назви не показуємо взагалі.

  Список має читатися з погляду, лист — бути юридично точним.
- **Числа плиток і карти зводимо до одного способу рахунку** — за географією меж.

  38,4% — шум, а карта через нього лишалася без шару «ДТП». Замінено порогом
  `MIN_PAI = 3.0`.

  джерелом для неї. Див. `NAUKA.md`, розділ 5.
