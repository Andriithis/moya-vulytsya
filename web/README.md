# web — сайт

**Що це:** те, що бачить користувач.

**Статус:** порожньо. Етап 5 дорожньої карти.

## Головний екран

Одне речення визначає все:

> Ти вводиш адресу і читаєш історії свого місця.

Пошук за адресою і карта — центр. Статистика — не центр.

## Що має бути в MVP

- карта з подіями
- пошук за адресою
- картка історії з посиланням на оригінал у ЄДРСР
- «що поруч» — 5 найцікавіших, а не 300 документів списком
- соти для приватного сектору, точки для публічних місць
- мобільна версія

## Візуальні рішення, які вже прийняті

**Соти для приватного сектору** — це не естетика, а наслідок правила точності
([`../docs/rishennya/0003-tochnist-heokoduvannya.md`](../docs/rishennya/0003-tochnist-heokoduvannya.md)).
Форма сама каже «це зона, а не адреса».

**Позиція камери в адресі сторінки** — будь-який вид можна надіслати
посиланням. Копійки в реалізації, великий ефект на поширення.

**Кольори нормуються під те, що зараз на екрані** — зумиш у тихий район і
контраст зберігається, а не все зелене.

**Покриття даних поруч із числами**, а не в примітках.

## Чого не робимо

- застережень посеред екрана (роботу чесності робить назва продукту)
- єдиного балу «Безпека: 73/100»
- оцінних ярликів районам
