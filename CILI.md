## Що це

«Моя вулиця» — **комерційний продукт просторової інформації про події міста**
на спільній базі судових подій
([dani-edrsr](https://github.com/Andriithis/dani-edrsr)): що, де й коли
сталося, з посиланням на рішення суду.

Продукт має два рівноправні consumer-входи:

1. **Дослідити місто** — карта → концентрації → проблемні зони → адреси → події.
2. **Перевірити конкретне місце** — пошук адреси → профіль місця → події →
   аналітичний контекст → порівняння / повний аналіз.

Сценарій перевірки місця може бути корисним перед орендою, купівлею або
переїздом, але продукт **не радить**, де жити, не дає safety score і не називає
будинки безпечними/небезпечними.

Повна концепція — [`docs/00-viziya.md`](docs/00-viziya.md).
Чинне рішення про consumer-монетизацію —
[`0012`](docs/rishennya/0012-adresa-first-monetyzatsiya.md).
Незмінні правила — [`AGENTS.md`](AGENTS.md).

## Два напрями — разом, не замість одне одного

1. **Карта для людей — FREE + платний аналіз.**
   FREE відповідає на «що тут відбувалося»: карта, адреси, події, фабули,
   базовий контекст і джерела.
   Платний продукт відповідає на «що це означає і чим це місце відрізняється»:
   динаміка, порівняння, часові патерни, контекст і повний аналіз місця.
   Перший consumer-тест — **разовий платний аналіз конкретної адреси/місця**.
   Підписка не є основною моделлю, доки не доведено утримання.
2. **Дані для організацій — API подій, API статистики, ліцензовані вибірки**
   ([0011](docs/rishennya/0011-dani-api-analohy.md)).
   Продається не доступ до відкритих рішень, а підготовка: події з точним
   місцем, фабули, джерела, оновлення та відкликання скасованого.

## Критерій успіху першого етапу

Перевірити попит, а не будувати все наперед:

- consumer: **хоча б одна реальна оплата за повний аналіз місця**;
- B2B: хоча б одна організація погодилась на тестовий доступ або ліцензію.

До цього вимірюємо воронку:
`visit → address search → place profile → fabula read → full analysis CTA → checkout → payment`.

## Продуктовий пріоритет

Після появи перевіреного випуску даних пріоритет consumer-інтерфейсу:

1. address autocomplete;
2. самодостатня картка/профіль адреси;
3. події й короткі фабули;
4. shareable URL конкретного місця;
5. mobile-first карта + нижня шторка;
6. частковий аналітичний preview;
7. CTA «Повний аналіз місця»;
8. порівняння двох адрес;
9. продуктова аналітика;
10. тільки потім — розширення PRO, підписка та другорядні функції.

## Межі, які не обговорюються

- Жодних балів небезпеки, «небезпечних будинків», прогнозів і тверджень
  про причини — [`AGENTS.md`](AGENTS.md), розділ 4.
- FREE-події, фабули та першоджерела не ховаємо за оплатою.
- Приватні виключення й точність місця — за правилами спільної бази.
- Власник — діючий поліцейський: створює базу й код (творча діяльність) і
  може отримувати роялті за ліцензією; операційну діяльність, продажі й гроші
  веде партнер. Перед будь-якою угодою — письмовий запит до НАЗК.
  [`docs/02-pravo.md`](docs/02-pravo.md), розділ 6.
