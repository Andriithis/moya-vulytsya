# Моя вулиця

**Карта історій, які розказали суди.**

Кожне судове рішення — це завершена історія: що сталося, коли, де і чим закінчилося.
В Україні таких історій мільйони, вони відкриті за законом, і ніхто в світі ще не
поклав їх на карту.

Ти вводиш адресу — і читаєш історії свого місця.

## Що де лежить

```
docs/        вся документація — тільки текст, коду немає
pipeline/    код, який готує дані: качає ЄДРСР, витягує адреси, шукає координати
db/          схема бази даних
api/         програма-посередник між базою і сайтом
web/         сам сайт
analytics/   розрахунки: кластери, сигнали, динаміка
data/        дані — у GitHub не потрапляють, лежать локально
legacy/      посилання на старий проєкт-прототип
```
