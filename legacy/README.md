# legacy — старий прототип

Тут немає коду. Старий проєкт живе у власному репозиторії:

## 👉 https://github.com/Andriithis/karta-kyiv

## Що це

**«Карта правопорушень Києва за даними ЄДРСР»** — інструмент для навчального
курсу з взаємодії поліції з населенням на засадах партнерства, Академія
патрульної поліції.

Робочий прототип: качає рішення з ЄДРСР, витягає з текстів адресу й час
правопорушення, наносить на карту міста, генерує статичний сайт.

Репозиторій `moya-vulytsya` спершу був повною копією цього проєкту. Копію
видалено, оригінал недоторканий.

## Що звідти варто взяти

| Що | Файли в karta-kyiv | Чому цінно |
|---|---|---|
| **Витяг адрес** | `src/addr.py`, `src/diag_addr_variants.py` | нормалізація українських адрес у судових текстах — найскладніша задача проєкту, тут вона вже вирішена |
| **Витяг фабул** | `src/step1b_fabula.py`, `src/diag_fabula.py` | обрізання опису до слів «чим вчинив», зупинка на «Суддя» і «Головуючий» |
| **Категоризація** | `src/labels.py`, `src/pravo.py` | відображення статей КУпАП і КК на категорії |
| **Геокодування** | `src/step2_geocode.py` | локальне зіставлення з адресною базою OpenStreetMap |
| **Списки виключень** | `data/vykluchennya*.txt` | вручну зібрані виключення — це багато годин ручної роботи |
| **Завантаження дампу** | `src/step0_fetch_dump.py`, `src/step1_download.py` | робота з архівом ЄДРСР |

## Чим новий проєкт відрізняється

| | karta-kyiv | moya-vulytsya |
|---|---|---|
| Аудиторія | слухачі академії | усі |
| Мета | навчальний інструмент | продукт |
| Продукт | карта правопорушень | **карта історій** |
| Зберігання | файли + статичний сайт | база даних + API |
| Точність координат | адреса | правило 8 адрес, соти для приватного сектору |
| Процесуальний статус | не відстежується | обов'язковий |
| Охоплення | Київ | Україна |

## Правило

**Код звідти не копіюємо механічно.** Беремо перевірену логіку свідомо, шматками,
переписуючи під нову модель даних і нові правила приватності.

Причина: старий проєкт має іншу архітектуру (статична генерація без бази),
яка не тягне часову машину, моніторинг і персональні зони.
