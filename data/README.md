# data — дані

**Вміст цієї папки у git не зберігається.** Тут лежать великі файли, які
завжди можна завантажити або згенерувати заново.

## Що тут має бути

| Файл | Звідки |
|---|---|
| архів ЄДРСР за рік | [data.gov.ua](https://data.gov.ua/organization/derzhavna-sudova-administratsiia-ukrayiny) |
| адресна база | OpenStreetMap |
| межі районів і мікрорайонів | відкриті дані |
| робоча база даних | створюється конвєєром |

## Що потрапляє в git

Тільки `fixtures/` — кілька десятків прикладів для тестів, без персональних
даних. Все інше ігнорується (див. `.gitignore`).

## Чому дані не в git

Git зберігає **кожну версію кожного файлу назавжди**. Один архів на 255 МБ,
покладений у git один раз, залишається в історії репозиторію назавжди, навіть
якщо файл видалити. Через кілька оновлень репозиторій стає непридатним для
роботи.

Правило: **у git — код, який обробляє дані. Дані — окремо.**
