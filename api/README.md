# api — посередник між базою і клієнтами

**Що це:** програма, у якої сайт і майбутній Android-додаток питають дані.
Сайт не звертається до бази напряму — ніколи.

**Статус:** порожньо. Етап 4 дорожньої карти.

## Навіщо це потрібно

Щоб сайт і додаток користувалися **однією логікою розрахунків**. Інакше через
рік цифри на сайті й у додатку розійдуться, і ніхто не зрозуміє чому.

## Що має вміти (мінімум для етапу 4)

| Запит | Повертає |
|---|---|
| події біля точки | список подій у радіусі, з рівнем точності кожної |
| подія за id | картка: історія, дата, категорія, посилання на оригінал |
| покриття території | повнота даних і геоточність за період |
| пошук за адресою | координата + що поруч |

## Правила

- **Ніколи не віддавати те, що відфільтроване** за
  [`../docs/03-dani-i-etyka.md`](../docs/03-dani-i-etyka.md)
- **Ніколи не віддавати координату без рівня точності** — клієнт має знати,
  що малювати: точку чи соту
- **Ніколи не віддавати число без його атрибутів** — період, територія,
  кількість подій, база порівняння
- Дата події і дата появи документа — **завжди окремі поля**
