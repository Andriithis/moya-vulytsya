# Додаток «Моя вулиця» для Android (Google Play) — план

ZAVDANNYA-06, 07.11.2026. Рішення MV-13: додаток для Android обов'язковий — це сайт,
загорнутий у додаток. **Тут лише план. Нічого не зібрано, облікових записів не створено.**

## Коротко

1. Сайт уже вміє встановлюватися на телефон: є маніфест, іконки 192 і 512 px, робочий файл
   кешу (`site/zahlushka/sw.js`), сторінки відкриваються без мережі, Chrome показує кнопку
   «Встановити» (перевірено 07.11 на локальній копії, `ZVIT-06.md`).
2. Для Google Play цей самий сайт загортаємо в «довірену вебоболонку» (Trusted Web Activity,
   далі — оболонка): це маленький додаток, який відкриває наш сайт у Chrome на весь екран,
   без адресного рядка. Код сайту при цьому не змінюється — оновили сайт, оновився й додаток.
3. Збирає оболонку програма **Bubblewrap** від Google (командний рядок): бере наш маніфест
   і робить готовий файл для Google Play.
4. Головні вимоги, які не обійти: **свій домен**, **обліковий запис розробника Google Play**
   (25 $ разово), **закрите тестування: 12 тестувальників 14 днів поспіль**, і —
   якщо в додатку продаємо підписку чи аналіз — **оплата через Google Play** (див. «Ризики»).

## Що робимо ми

1. **Перед оболонкою** — сайт на домені з https, маніфест і робочий файл кешу (готово для
   заглушки; для карти — повторити, коли буде карта).
2. **Збирання оболонки** (на комп'ютері з Node.js; Bubblewrap сам довантажує Java і Android SDK):
   ```
   npm i -g @bubblewrap/cli
   bubblewrap init --manifest https://[ДОМЕН]/manifest.webmanifest
   bubblewrap build
   ```
   `init` питає назву пакета (наприклад, `ua.[домен].app` — змінити потім не можна), колір,
   іконки (бере з маніфесту, зокрема масковану `ikona-maskable-512.png`). `build` дає файл
   `.aab` для Google Play. Налаштування — файл `twa-manifest.json`; його зберігаємо в
   репозиторії, ключі — ні.
3. **Підтвердження домену**: після першого завантаження в Google Play беремо з Play Console
   відбиток ключа підпису (SHA-256) і кладемо на сайт файл `/.well-known/assetlinks.json`
   (Bubblewrap уміє його згенерувати: `bubblewrap fingerprint add …`, потім `bubblewrap fingerprint generateAssetLinks`). Без цього файла додаток
   відкриватиметься з адресним рядком угорі — виглядає як браузер, а не додаток.
4. **Перевірка на телефоні** до тесту: адресного рядка немає, сайт працює без мережі,
   форми передзамовлення й звернення надсилаються, кнопка «назад» поводиться нормально.
5. **Закрите тестування** — 12 тестувальників, 14 днів. Канал у чотирьох числах для
   встановленого додатка вже є: стартова адреса маніфесту — `index.html?dzherelo=dodatok`.
6. **Заявка на вихід у загальний доступ** з Play Console → публікація (лише після «так» Андрія).
7. **Оновлення**: зміни сайту доходять до додатка самі. Нова збірка оболонки потрібна лише
   при зміні назви, іконки, кольорів або вимог Google (наприклад, нової версії Android).

## Ризики — сказати одразу

1. **Оплата в додатку — через Google Play.** Правила Google Play: додатки, що продають
   цифрові товари чи підписки, мають використовувати оплату Google Play. Для оболонки це
   робиться через Digital Goods API і Payment Request API (Chrome 101+) і прапорець
   `playBilling` у `twa-manifest.json`. Наслідки:
   - Google бере комісію з кожної оплати в додатку; ціни 399 і 690 грн (MV-28) в додатку
     або дадуть менше грошей, або мають бути іншими — рішення за Андрієм;
   - гроші з Google Play приходять **власнику облікового запису розробника**. Андрій не може
     приймати платежі і вести операційну діяльність (`AGENTS.md`, розділ 11). Отже,
     **обліковий запис розробника, через який іде продаж, має бути на партнера** (бажано
     організацію; для організації Google просить номер D-U-N-S — безкоштовний, але
     оформлення займає час). Якщо обліковий запис буде на Андрія, продажу в додатку бути не
     повинно — лише безкоштовна карта й ігри.
   - Варіант без комісії — додаток без продажу всередині (лише безкоштовне), а купівля —
     на сайті. Чи дозволяють правила Google Play посилання з додатка на оплату на сайті —
     **не перевірено**, перед рішенням треба перечитати чинні правила.
2. **12 тестувальників на 14 днів** — найдовший крок; людей шукати заздалегідь.
   Для облікового запису організації ця вимога, за даними Google, не діє (лише для особистих,
   створених після 13.11.2023) — ще одна причина реєструвати на партнера-організацію.
3. **Домен обов'язковий** для оболонки без адресного рядка. Без домену — лише встановлення
   з браузера (кнопка «Встановити»), без Google Play.
4. **Політика конфіденційності** має згадати, що додаток — це той самий сайт; анкету
   «безпека даних» заповнюємо за тими самими полями (контакт, адреса, згода; без кукі й
   ідентифікаторів).
