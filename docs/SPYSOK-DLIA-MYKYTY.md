## Акаунти, домен, автопостинг (ZAVDANNYA-131, `docs/AKAUNTY-PAKET.md`)

Покроково — [`AKAUNTY-PAKET.md`](AKAUNTY-PAKET.md) (зустріч 20.11). Коротко: пошта Gmail проєкту; домен
`moyavulytsya.com.ua` на nic.ua (≈ 713 грн/рік) — це й є п. 1 таблиці вище; Cloudflare Free (хостинг не купувати);
організація GitHub з приватним репозиторієм `avtopostynh` для автопостингу без сервера (`docs/AVTOPOSTYNH.md`, розд. 9);
Telegram-канал і бот, YouTube, Facebook (сторінка й бізнес-портфоліо Meta), Instagram (бізнес, прив'язаний до сторінки),
TikTok (бізнес), X — усе на ім'я `moyavulytsya`. Двофакторний вхід скрізь; паролі — лише в менеджері паролів.
Сервер Hetzner — вимкнути після завантаження України (≈ місяць, MV-153).

## Запуск сайту (ZAVDANNYA-132, `docs/ZAPUSK-SAITU.md`)
