# Діагностика вибірки й сліпа форма

Дата: 16.09.2026. Це розробницьке дослідження асистента, не незалежний QA.

## Що означає нуль EVENT_LOCATION

Вибірка 200 документів — випадкова серед активних документів київських
районних судів, а не серед підтверджених подій. Метадані звірено з тим самим
офіційним ZIP, що описаний у [перевірці джерел](phase2-reference-validation.md).
Сліпі тексти та людські відповіді для налаштування правил не читалися.

| Ознака | Кількість |
|---|---:|
| Цивільне судочинство | 124 |
| Кримінальне | 57 |
| Адмінправопорушення | 17 |
| Адміністративне | 2 |
| Ухвали | 154 |
| Рішення | 24 |
| Постанови | 17 |
| Вироки | 4 |
| Судові накази | 1 |
| Категорії з поточного словника продукту, без домашнього насильства | 24 |

Найбільша категорія — позики/кредити/вклади (43); надання послуг і ДТП
з пошкодженням майна — по 10. Отже, значна частина вибірки не відповідає
цільовим темам. Ухвала може містити опис події, а вирок — приховану адресу:
метадані не дають автоматичної відповіді про придатність кожного документа.
Причину **всіх** 200 відмов можна встановити лише після сліпої розмітки.
Precision лишається невизначеним, recall невідомим.

## Окреме розробницьке дослідження

Приватний каталог: `private/diagnostics-2026-09-16/`. Збережено метадані,
оригінальні RTF і декодовані тексти 20 інших документів. Відбір: активні
київські документи, категорія з `src/labels.py:CODE` без `ДОМ`, форма
«вирок» або «постанова». Порядок — SHA-256 від
`phase2-dev-diagnostics-v1|doc_id`; взято 100 найменших ключів, виключено
справи сліпої вибірки й узято перші 20. Перетину номерів справ немає.
Це цільова розробницька вибірка, її частки не переносимо на весь дамп.

Склад: 19 постанов і 1 вирок; 15 документів категорії ДТП. Кандидати є
в 15 документах. Усі 20 RTF оголошують cp1251, Unicode-команд `\uN` немає;
переглянуті розробницькі фрагменти читаються. Масове зникнення тексту при
декодуванні тут не підтвердилося. Це не повна валідація RTF-декодера.

Підтверджено й виправлено на синтетичних регресіях:

- прийменник «в»/«у» перед позначенням міста поглинався номером будинку;
- кілометрова позначка дороги приймалася за номер будинку;
- конструкція «за адресою … водій ОСОБА_N керував …» не впізнавалася.

Версію витягувача підвищено до `location-roles-v3`, щоб старі докази не
вважалися результатом нових правил. Після змін є 1 кандидат EVENT_LOCATION,
але вибраних місць документа все ще 0: інша згадка тієї самої адреси має
заборонену роль, тому перевірка конфлікту правильно зупиняє автоматичний вибір.
Сліпу вибірку повторно новими правилами не обробляли.

Невирішені пропуски: дієприслівник «керуючи», конструкції ДТП із «не
дотримався», альтернативні назви в дужках, скорочення «пр-т.», Кільцева
дорога, надто широкий контекст згадок суду/поліції. Не знято заборони на
заперечення, процесуальні дії, конфлікти ролей чи кілька адрес. Потрібні
окремі рішення й негативні приклади перед розширенням правил.

## Перша ручна порція

Локальний файл: `private/manual-review-2026-09-16/index.html`.
Відкрити у звичайному браузері подвійним натисканням. Він містить перші
20 записів сліпого файла в незмінному порядку. Мережевих запитів немає;
прогнози, попередні відповіді й `withheld/` генератор не читає.

1. Вказати ім’я або код перевіряльника.
2. Прочитати документ; позначити наявність місця, відсутність, сумнів або
   нечитабельність. Для місця додати адресу й цитату; перелічити інші ролі.
3. Натиснути «Зберегти відповіді», переконатися в завантаженні JSON і
   перенести файл у приватну папку. Перед закриттям обов’язково зберігати.
4. Для продовження обрати збережений файл. Форма перевіряє контрольну суму
   набору та відповідність документів; чужий файл не замінить відповіді.

Це перший прохід текстової розмітки `blind-review-notes-v1`, а не завершений
географічний QA. Координати, перейменування та спірні відповіді перевіряються
окремо; автоматичного перетворення цих нотаток на еталон чи публікацію немає.

Відтворення для нового вихідного файла (наявний не перезаписується):

```text
python -m pipeline.qa_review_form --source private/qa-2026-09-15/review-ready.jsonl --output private/manual-review-new/index.html --limit 20
```

Контрольні суми всіх 407 файлів початкового QA-пакета до й після роботи
збіглися. Приватні матеріали не включені в Git. Локально 79 тестів:
66 пройшли, 13 PostgreSQL пропущені без тестової БД. Форма перевірена
тестами генератора (екранування тексту, відсутність прогнозів, контрольні
суми, заборона перезапису й публічних шляхів). Інтерактивна перевірка у
браузері не виконана: політика інструмента заблокувала локальний file URL.
