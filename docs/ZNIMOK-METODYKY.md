# Знімок методики й позначка часу — щомісяця (інструкція)

ZAVDANNYA-158, 20.11.2026. Навіщо — `docs/METODYKA-BAZY.md`, розд. 8: дата коміту в git не доводить, коли правило
з'явилося; **кваліфікована електронна позначка часу** на хеш знімка — доводить (її ставить кваліфікований надавач
довірчих послуг, ЗУ «Про електронну ідентифікацію та електронні довірчі послуги»). Займає ≈ 15 хвилин на місяць,
коштує 0 грн, якщо в Микити вже є КЕП (ключ ФОП чи Дія.Підпис).

## Хто що робить

| Крок | Хто | Що |
|---|---|---|
| 1 | ПК (Андрій або виконавець), після випуску даних | знімок методики — одна команда (нижче); надіслати Микиті файл `metodyka-<дата>.sha256` (70 байт, нічого секретного) |
| 2 | **Микита** | підписати цей файл своїм КЕП з позначкою часу; повернути файл підпису й час позначки |
| 3 | ПК | зберегти архів, опис, хеш і підпис у двох місцях поза GitHub; рядок у `avtorstvo/zhurnal.tsv` — комітом |

Сам архів (`.zip`) Микиті не надсилати й нікуди не викладати: у ньому код приватного `dani-edrsr`. Позначку ставлять на
**хеш** — він нічого не розкриває, а збіг хешу доводить, що саме цей архів існував на час позначки.

## Крок 1. Знімок (ПК)

Обидва репозиторії — поруч в одній теці, на свіжому `main`:

```bash
git -C dani-edrsr pull
```

```bash
git -C moya-vulytsya pull
```

```bash
python moya-vulytsya/avtorstvo/znimok_metodyky.py --zhurnal
```

Програма пише в `moya-vulytsya/avtorstvo/znimky/` (git цю теку не бачить) три файли:
`metodyka-<дата>.zip`, `metodyka-<дата>.MANIFEST.tsv` (коміти й список файлів з хешами), `metodyka-<дата>.sha256`
(один рядок: хеш архіву й ім'я). З `--zhurnal` — ще й рядок у `avtorstvo/zhurnal.tsv` з прочерками в полях підпису.

## Крок 2. Позначка часу (Микита)

Порада — **підпис з кваліфікованою позначкою часу на сайті id.gov.ua** (сервіс «Підписати документ», безкоштовно, працює з
файловим ключем, апаратним ключем і Дія.Підписом):

1. Відкрити id.gov.ua → «Підписати документ» (електронний підпис).
2. Обрати свій ключ (КЕП) і ввести пароль або підтвердити в Дії.
3. Завантажити файл `metodyka-<дата>.sha256`.
4. Формат підпису — **CAdES**, тип — **окремий файл підпису** (detached) або «дані й підпис в одному файлі»; рівень —
   **з позначкою часу** (у переліку зазвичай «CAdES-X Long» або «з позначкою часу» — головне, щоб у підписі був час
   від надавача, а не з комп'ютера).
5. Зберегти результат (`.p7s`).
6. Перевірити: id.gov.ua → «Перевірити підпис» → завантажити `.p7s` (і `.sha256`, якщо підпис окремий). У результаті має
   бути рядок на кшталт «Час підпису (підтверджено кваліфікованою позначкою часу для підпису)» з датою й часом.
   Записати цей час.
7. Надіслати назад `.p7s` і час позначки (будь-яким каналом — секретного там нічого немає).

**Не перевірено:** точні назви пунктів меню й рівнів підпису на id.gov.ua — з пам'яті, сьогодні сайт не відкривали. Якщо
пунктів інші — шукати варіант, у результаті перевірки якого є «кваліфікована позначка часу». Те саме можна зробити в
програмі свого надавача КЕП (наприклад, у застосунку банку чи АЦСК, де видано ключ) — аби підпис був з позначкою часу.

Чому підпис Микити, а не Андрія: позначка доводить **час існування** файлу, а не авторство; авторство Андрія доводять
методика й журнал рішень (`METODYKA-BAZY.md`, розд. 9, п. 1). Підписати може будь-хто з КЕП, Микиті — найпростіше, бо
ключ ФОП у нього вже є.

**Запасний і додатковий шлях (безкоштовно, без КЕП):** OpenTimestamps — `ots stamp metodyka-<дата>.sha256` (програма
`opentimestamps-client`); позначка в блокчейні Bitcoin, не кваліфікована за законом України, але незалежна й безстрокова.
Можна робити разом із кваліфікованою — не замість неї.

## Крок 3. Зберегти (ПК)

1. Покласти `.p7s` поруч з трьома файлами знімка.
2. У `avtorstvo/zhurnal.tsv` замінити прочерки останнього рядка: `pidpys` — ім'я файлу `.p7s`, `chas_poznachky` — час з
   перевірки (як показав id.gov.ua). Коміт у `moya-vulytsya`: «Знімок методики <дата>: позначка часу».
3. Чотири файли (`.zip`, `.MANIFEST.tsv`, `.sha256`, `.p7s`) — **у двох місцях поза GitHub**: диск проєкту (обліковий
   запис партнера) і диск Андрія. Не в публічний репозиторій.

## Перевірити через рік (будь-хто з доступом до обох репозиторіїв)

```bash
python moya-vulytsya/avtorstvo/znimok_metodyky.py --pereviryty moya-vulytsya/avtorstvo/znimky/metodyka-<дата>.sha256
```

Програма перебудовує архів з комітів, записаних в описі, і звіряє хеш з файлом (і з самим архівом, якщо він поруч).
«Збігається» означає: правила на цих комітах — саме ті, на які поставлено позначку часу. Якщо архіву на диску вже немає —
досить історії git і файлу `.sha256` з підписом.
