### 2.4. Порада: R2, файли-пачки на клітинку

**Брати R2** — і не переписувати рушій: тека, яку вже збирає `karta_pidpysnyka.py`, кладеться в приватне сховище як є.
Київ і вся Україна вміщаються в безкоштовні 10 ГБ; D1 для подій не потрібна (D1 лишається для замовлень і форм, MV-157).

Що коштуватиме: **0 $**, доки сайт у межах 100 тис. викликів скрипта на добу. Одне відкриття карти — ≈ 10 файлів старту
+ клітинки, які людина переглядає (≈ 20–40 викликів), тобто **≈ 2,5–5 тис. відкриттів карти на добу** разом зі сторінками
будинків. Коли підписників стане стільки — план Workers Paid, **5 $/міс** (10 млн викликів), і ця межа зникає. Друга
межа Free — 10 мс процесора на виклик: файли карти скрипт не розбирає (лише передає), а «події адреси» розбирають одну
клітинку — до 657 КБ на пробі; на ПК це ≈ 1–3 мс, **на Cloudflare не міряно**. Якщо впреться — ділити клітинки дрібніше.

### 4.4. Стеля витрат, збої

- **Жорстка стеля — у консолі Anthropic** (ліміт витрат на робочий простір, у якому ключ): пропоную **10 $ на місяць** —
  це ≈ 100–200 «важких» довідок або тисячі звичайних. Дійшли — API відповідає помилкою, довідки однаково йдуть з описами правилами.
- **М'яка стеля в коді** — `SHI_STELIA_USD` (типово 10 $; ставити трохи нижче за жорстку, напр. 8 $): витрачене за місяць —
  у файлі `<kesh>/shi-vytraty-<рррр-мм>.json`; дійшли — команда в API не йде.
- **Збій** (мережа, 429, 5xx) — SDK повторює 2 рази, генератор — ще до 3 разів; не вийшло — у довідці опис правилами (S-П.1),
  як зараз без `--shi`. **Без повтору** (стеля, відмова моделі, немає ключа чи бібліотеки) — одразу правила: без цього
  Оболонь чекала б ≈ 11 хв марних повторів (`dani-edrsr/src/zvit/perekazy.py`, «bez_povtoru»).
- Ключ — лише секрет `ANTHROPIC_API_KEY` у GitHub (і змінна на ПК Микити, якщо запускати там); у файлах — ніколи.
- Тести: `tests/test_prodazh.py`, `ShiApi` — формат відповіді, ціна з токенів, кеш інструкції (запит лише поділено, не змінено),
  стеля (за нею в API не ходимо), збій і відмова, без ключа — одразу правила. Справжній генератор з цією командою без ключа —
  довідка Осінньої, 32 за 4 с з описами правилами.

**Не перевірено:** жодного справжнього виклику API (немає ключа) — токени й ціни вище оцінкові; якість переказу Haiku 5.5
на нашому запиті; поведінка кешу на справжньому API (`cache_read_input_tokens` > 0 — перевірити на першій довідці).
