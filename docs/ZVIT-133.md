## 0. Коротко для Андрія

- **Платне можна тримати без власного сервера і без Supabase.** Усе — на тому самому безкоштовному Cloudflare, що й сайт,
  плюс GitHub, який уже є.
- **Карта підписника** (адреси й описи подій) — у закритому сховищі файлів Cloudflare. Сайт віддає її лише тому, хто
  увійшов і має оплачену підписку. Київ за 10 років — ≈ 0,3–0,45 ГБ, уся Україна — ≈ 3–3,5 ГБ: усе вміщається в
  безкоштовні 10 ГБ. Базу на кшталт Supabase для цього не треба.
- **Довідки** збирає той самий генератор, але не на сервері, а на машині GitHub, яку сайт сам «будить» після оплати.
  Від оплати до листа — ≈ 2–4 хвилини. Безкоштовно до ≈ 400–600 довідок на місяць.
- **Перекази подій людською мовою** — найдешевша модель Claude (Haiku 5.5): ≈ 1–5 грн на довідку. Стеля — 10 $ на місяць.
  Якщо ШІ недоступний чи стелю вичерпано — довідка однаково приходить, просто з описами без переказу.
- **Перевірка форм двічі на добу** тепер дивиться в базу Cloudflare, а не в Supabase.
- **Микиті** — 7 пунктів у [`docs/SPYSOK-DLIA-MYKYTY.md`](docs/SPYSOK-DLIA-MYKYTY.md) (розділ «Платна частина»): найважливіші —
  ключ Claude зі стелею 10 $/міс і закритий репозиторій для збирання довідок.

## 2. Що не перевірено — чесно

- **Нічого не запускалось на справжньому Cloudflare, GitHub Actions чи Claude**: у хмарі немає акаунтів і ключів. Усе
  перевірено справжнім кодом на моїй машині, на справжніх даних пробного випуску.
- **Ціна переказу — оцінка:** скільки токенів дає українська мова, я оцінив з довжини тексту; справжнє число буде з першої
  довідки. Якість переказу на новій моделі Haiku 5.5 не дивився: перед продажем — 20 подій очима (≈ 1 цент).
- **2–4 хвилини від оплати до листа** — оцінка: старт машини GitHub і кеш даних не міряні (без налаштованого репозиторію не запустити).
- **Повний Київ** (21.11) у кеш GitHub може не влізти, якщо випуск справді ≈ 7 ГБ — тоді генератору потрібен «вузький» випуск.
- Карта OpenStreetMap для генератора — з BBBike (вирізка Києва); у звітах 84 була інша (`kiev-latest`). Різниці не порівнював.
- Чи не відсікає захист Cloudflare від ботів перевірку форм із GitHub — не знаю.
