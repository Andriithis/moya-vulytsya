# Запуск сайту на Cloudflare — покроково (ZAVDANNYA-132)

Для Микити. Хмара, 19.11.2026. Хостинг — Cloudflare Workers (MV-105), домен — `moyavulytsya.com.ua` (`docs/AKAUNTY-PAKET.md`).
Ключі й паролі — лише в менеджері паролів, у «секретах» Cloudflare чи GitHub і в змінних середовища. **Ніколи** — у файли,
чат чи пошту. Що тут **не перевірено** на справжньому акаунті — розд. 10.

## 1. Коротко

- Сайт збирається **одним запуском** з будь-якого випуску даних (зараз — пробний 08.11, після 21.11 — повний Київ) —
  код міняти не треба: `python site/vyklasty.py <тека випуску>`. Скрипт сам збирає, створює таблиці бази, викладає й
  перевіряє живий сайт.
- **Поки оплату не підключено — режим «скоро»** (`MV_OPLATA=skoro`, типово): на кожній кнопці оплати другий рядок
  «Скоро — залиште пошту»; кнопка веде на сторінку, де людина лишає пошту, а ми зберігаємо, **що** вона хотіла купити і
  **для якого будинку**. Ціни, кнопки й шлях оплати вже готові.
- **Увімкнути оплату** = `MV_OPLATA=tak` + ключі LiqPay + ще раз той самий запуск (розд. 8).
- Форми сайту (передзамовлення, звернення «прибрати подію», «скоро», лічильник «чотири числа») — у базі Cloudflare **D1**
  того ж акаунта. Supabase для форм не потрібен (розд. 9).
- Платимо лише за домен. Cloudflare Workers, D1, пошта на домені й лічба відвідувань — безкоштовно на старті.

## 2. Що встановити на комп'ютер (раз)

- **Python 3.12+** (python.org) і `python -m pip install h3 pillow`.
- **Node.js 22 LTS** (nodejs.org) — через нього працює `npx wrangler` (інструмент Cloudflare, ставиться сам).
- Обидва репозиторії поруч: `moya-vulytsya` і `dani-edrsr` (з нього беремо довідник перейменувань вулиць).

Або без свого комп'ютера — кнопкою в GitHub (розд. 4б).

## 3. Підготовка (раз, ≈ 40 хв)

**3.1. Домен у Cloudflare.** Як у `docs/AKAUNTY-PAKET.md`, крок 3: домен додано, сервери імен на nic.ua замінено,
Cloudflare написав «active».

**3.2. Пошта на домені — отримувати.** Cloudflare → домен → Email → **Email Routing** → увімкнути → адреса
`pochta@moyavulytsya.com.ua` → пересилати на Gmail проєкту → підтвердити лист. Безкоштовно. Ця адреса — `[КОНТАКТ]` в оферті.

**3.3. Пошта на домені — надсилати з сайту** (листи «нове звернення» партнеру; після ввімкнення оплати — довідки й вхід
у кабінет). Порада — **Resend** (resend.com, безкоштовний план; межі перевірити на сайті): Add Domain →
`moyavulytsya.com.ua` → записи DNS, які він покаже, додати в Cloudflare → DNS (або кнопкою автоматичного налаштування
Cloudflare, якщо запропонує) → API Keys → створити ключ лише на надсилання → **одразу** в секрет (крок 3.7), більше нікуди.
Без цього кроку сайт працює, але листів не надсилає (`MV_POSHTA_SERVIS=zahlushka`) — тоді звернення треба дивитися
вивантаженням щодня (розд. 9).

**3.4. Токен Cloudflare для викладки.** My Profile → API Tokens → Create Token → шаблон **Edit Cloudflare Workers** →
додати право **Account → D1 → Edit** (якщо в шаблоні його немає) → Account Resources: лише свій акаунт; Zone Resources:
лише `moyavulytsya.com.ua`. Токен — у менеджер паролів і в секрет GitHub `CLOUDFLARE_API_TOKEN`. Ідентифікатор акаунта
(Account ID, праворуч на головній сторінці домену) — `CLOUDFLARE_ACCOUNT_ID`.

**3.5. База D1** (замовлення, форми, «скоро»). У теці `moya-vulytsya`, з токеном у змінній середовища:

```bash
npx wrangler d1 create moya-vulytsya-prodazh --location weur
```

Скопіювати `database_id` (вигляд `xxxxxxxx-xxxx-…`) — це `MV_D1`. Не секрет, але й публікувати не треба. `weur` — Західна
Європа (так у політиці конфіденційності: «база в ЄС»).

**3.6. Лічба відвідувань без кукі.** Cloudflare → Analytics & Logs → **Web Analytics** → Add a site →
`moyavulytsya.com.ua` → обрати **ручне** встановлення (JS snippet), **не** автоматичне (автоматичне заблокує захист
сторінок) → скопіювати лише `token` з фрагмента (32 знаки) → це `MV_CF_ANALITYKA`. Токен публічний (його видно в коді
сторінок), кукі немає. Окремо, без жодного коду, Cloudflare показує загальний трафік домену: домен → Analytics.

**3.7. Секрети Workers** — **після першої викладки** (розд. 4), у теці `_vykladka/sait-worker`, яку пише скрипт:

```bash
npx wrangler secret put ADMIN_KLIUCH
```

`ADMIN_KLIUCH` — придумати довгий випадковий (менеджер паролів → «згенерувати», 40+ знаків): ним партнер вивантажує
форми й видаляє дані на запит. З Resend — ще `npx wrangler secret put POSHTA_KLIUCH`. Ключі LiqPay — розд. 8.

**3.8. Дані партнера для оферти й політики.** Скопіювати `site/zapovnennya.zrazok.json` **поза репозиторій**
(напр. `~/mv/zapovnennya.json`), вписати 9 рядків (що де — `docs/ZVIT-130.md`, «Що вписати Микиті»). Шлях до файла —
`MV_ZAPOVNENNYA`. Без нього скрипт не викладе сайт: оферта з `[ВЛАСНИК]` не публікується.

## 4. Викладка одним запуском

### 4а. Зі свого комп'ютера

Змінні середовища (у PowerShell — `$env:MV_DOMEN = "moyavulytsya.com.ua"`; у bash — `export MV_DOMEN=moyavulytsya.com.ua`):

| Змінна | Значення |
|---|---|
| `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID` | крок 3.4 |
| `MV_DOMEN` | `moyavulytsya.com.ua` |
| `MV_D1` | крок 3.5 |
| `MV_OPLATA` | `skoro` (до оплати) або `tak` (розд. 8) |
| `MV_ZAPOVNENNYA` | крок 3.8 |
| `MV_CF_ANALITYKA` | крок 3.6 (можна порожньо — тоді без лічби) |
| `MV_POSHTA_PARTNERA` | куди писати про нові звернення, напр. `pochta@moyavulytsya.com.ua` |
| з Resend: `MV_POSHTA_SERVIS`, `MV_POSHTA_URL`, `MV_POSHTA_VID` | `http-json`, `https://api.resend.com/emails`, `Моя вулиця <lysty@moyavulytsya.com.ua>` |

Тека випуску — файли з Release `dani-edrsr` (Андрій дає посилання): `events-<дата>.db` (або `.db.xz`) і, якщо є,
`budynky-*.json`, `perekazy-*.json`, `sudova-praktyka*.json`, `koloda-*.json`. Чого немає — того розділу на сайті не буде
(напр. без `budynky-*.json` немає сторінок будинків). Спершу сухо — нічого не змінює:

```bash
python site/vyklasty.py ~/mv/vypusk-2026-11-08 --suho
```

Усе добре — справжня викладка:

```bash
python site/vyklasty.py ~/mv/vypusk-2026-11-08
```

Скрипт друкує 5 кроків і наприкінці — перевірку живого сайту (✓ / ✗). Перша викладка прив'язує домен (Cloudflare сам
робить запис DNS і сертифікат) — сайт може відкритися за кілька хвилин; якщо щось ✗ — запустити ще раз за 5 хв.

### 4б. Кнопкою в GitHub (без свого комп'ютера)

Файл `site/github/vyklasty.yml` покласти в **приватний** репозиторій організації (той самий, що для автопостингу) як
`.github/workflows/vyklasty.yml`. Секрети: `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `MV_DANI_TOKEN` (вже є для

`MV_CF_ANALITYKA`, `MV_POSHTA_*`. Запуск: Actions → «Викладка сайту» → Run workflow → тег випуску (`vypusk-2026-11-08`).

## 6. Що перевірити після (10 пунктів)

Пункти 1–6 скрипт перевіряє сам (розд. 4); 7–10 — очима, з телефона.

1. `https://moyavulytsya.com.ua/` відкривається, замок у браузері (сертифікат), `http://` переводить на `https://`.
2. `/robots.txt` — є рядок `Sitemap: https://moyavulytsya.com.ua/sitemap.xml`; `/sitemap.xml` відкривається.
3. `/pro-dani/` — є розділ «Рішення, що ще не набрали законної сили».
4. Будинок (якщо є сторінки будинків) → кнопка «Довідка — 199 грн / Скоро — залиште пошту» → сторінка показує той самий
   будинок і ціну.
5. Оферта й політика (`/zahlushka/oferta.html`) — ваші дані, жодних `[ВЛАСНИК]` у квадратних дужках.
6. Форма пише в базу (скрипт надсилає тестовий запис із каналом `perevirka`).
7. Залишити свою пошту на `/oplata/?tovar=dovidka` → «Дякуємо!» → вона є у вивантаженні (розд. 9).
8. Заповнити звернення `/zahlushka/zvernennya.html` → на `MV_POSHTA_PARTNERA` прийшов лист «Нове звернення» (з Resend).
9. Карта: відкривається, соти видно, гра «Вгадай» відкривається (якщо була колода).
10. Google Search Console (search.google.com/search-console) → додати домен (запис DNS — у Cloudflare) → Sitemaps →
    `https://moyavulytsya.com.ua/sitemap.xml`. Cloudflare → Web Analytics: за годину з'явились відвідування.

## 7. Якщо щось пішло не так — відкат

У теці `_vykladka/sait-worker`: `npx wrangler deployments list` (список викладок) і `npx wrangler rollback` (повернути
попередню). Або в панелі: Workers & Pages → `moya-vulytsya` → Deployments → попередня → Rollback. Відкат не чіпає базу
(форми й замовлення лишаються).

## 8. Увімкнути оплату (коли ФОП і договір LiqPay)

1. Cloudflare: сховище для файлів довідок — `npx wrangler r2 bucket create moya-vulytsya-dovidky` (без нього «tak» не
   викладеться).
2. Секрети (у `_vykladka/sait-worker`): `LIQPAY_PUBLIC_KEY`, `LIQPAY_PRIVATE_KEY` — **спершу ключі пісочниці** з кабінету
   LiqPay (`sandbox_…`); `VYDACHA_KLIUCH` — придумати (той самий — у видавача довідок, `docs/PRODAZH-SERVER.md`, розд. 6).
3. Змінні: `MV_OPLATA=tak`, `MV_PLATIZHNYI_SERVIS=liqpay`, `MV_LIQPAY_SANDBOX=tak` → той самий запуск (розд. 4).
   Кнопки втрачають «Скоро», `/oplata/` веде до LiqPay, з'являється кабінет.
4. **Тестовий режим:** купити довідку тестовою карткою LiqPay → «Дякуємо» → довідка за 1–3 хв → лист. Оформити й
   скасувати підписку. Якщо LiqPay відкидає підпис — у панелі Workers додати змінну `LIQPAY_HESH=sha3-256`.
   Перевірити, що на формі є обов'язкова галочка «Прошу надіслати одразу; після надсилання відмовитися не можна» (MV-155, П6).
5. Бойові ключі замість пісочниці, `MV_LIQPAY_SANDBOX` — порожньо, ще раз запуск. Одна справжня покупка на 199 грн і
   повернення через кабінет LiqPay.
6. Написати **один раз** усім, хто лишив пошту в «скоро» (вивантаження `skoro`, розд. 9): «відкрили, ось посилання на ваш
   будинок». Після листа — позначити `napysano` (або видалити рядки), щоб не писати вдруге.

«Судова практика» (`spdovidka`, `spyurist`) ще не продається (немає в оферті) — її кнопки лишаються «скоро» і після
ввімкнення оплати.

## 9. Де читати форми

Вивантаження в таблицю (відкривається в Excel / Google Таблицях), таблиця — `skoro`, `zayavka`, `zvernennya` або `podiya`:

```bash
curl -H "Authorization: Bearer $ADMIN_KLIUCH" https://moyavulytsya.com.ua/api/admin/vyvantazhennia/zvernennya -o zvernennya.csv
```

Або одразу в базі: `npx wrangler d1 execute moya-vulytsya-prodazh --remote --command "SELECT * FROM zvernennya WHERE zakryto IS NULL"`.
**Звернення — відповісти протягом 10 робочих днів** (AGENTS.md, розд. 7); після відповіді —
`UPDATE zvernennya SET zakryto = unixepoch() WHERE id = <номер>`. Видалити чиюсь пошту з «скоро» на прохання —
`DELETE FROM skoro WHERE poshta = '<пошта>'`.

## 10. Що не перевірено (хмара, 19.11)

- **Нічого не викладалось на справжній Cloudflare**: немає акаунта й токена. Перевірено: збирання з пробного випуску 08.11,
  `wrangler deploy --dry-run` (wrangler 4.165), справжній код Workers локально з усіма сторінками на телефоні.
- Права токена з шаблону «Edit Cloudflare Workers» для D1 і свого домену; `wrangler d1 execute --yes`; прив'язка домену
  через `custom_domain` — за документацією Cloudflare, не на акаунті.
- Resend: тарифи, записи DNS, формат відповіді — за документацією; листи не надсилались.
- Web Analytics: що скрипт лічби проходить захист сторінок — перевірено в тексті сторінок, не у браузері зі справжнім токеном.
- LiqPay `sandbox = 1` — за документацією; на ключах пісочниці не перевірено.
- Файл для GitHub (`site/github/vyklasty.yml`) — жодного запуску на GitHub.
