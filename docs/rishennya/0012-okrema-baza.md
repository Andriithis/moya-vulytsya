# 0012. Окрема база для «Моєї вулиці»

**Статус:** прийнято власником у чаті 08.10.2026.

Працюємо з двома репозиторіями: продукт `moya-vulytsya` та окрема база
`dani-edrsr`. Навчальний проєкт незалежний і поза межами роботи: не змінювати
його код, дані, розклади, доступи та налаштування.

Попередні згадки «спільна база для двох продуктів» збережено як історію,
вони не задають поточну архітектуру й не дозволяють переносити навчальний код.
База готується для «Моєї вулиці» та потенційного окремого продукту даних/API;
продаж і тарифи доступу ще не запущено.

Правила підтвердження епізоду, приватності, точності геоприв'язки та фабул
не змінюються. Наявний архів текстів не прирівнюється до перевіреної бази подій.
Докладна звірка збережена локально у `dani-edrsr/docs/ZVIRKA-2026-10-08.md`.
