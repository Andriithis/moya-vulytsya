# 0011. Фабула та база як окремий продукт: аналоги

Дата перевірки: 28.09.2026. Статус: дослідження й рекомендація.
Два тексти уточнені власником; запуск продажу, тарифи та клієнтські
зобов’язання цим документом не затверджуються.

## Висновок

Готувати спільну базу до окремого продукту даних доцільно. Перша цінність —
підтверджені події, їхня географія, джерела, коректні фабули, оновлення й
відкликання. Для карти лишаються два змістові тексти: рішення та фабула.
Службові позиції доказів у рішенні — не третій текст для користувача.

Комерційний API — програмний спосіб отримати дозволені записи й статистику,
а не пароль до внутрішньої бази. Карту, навчальний проєкт і майбутній API
доцільно живити з однієї перевіреної бази, з окремими дозволами на видачу.
Наявний фундамент готує це технічно; платного API зараз немає.

## Що підтверджують первинні джерела

| Сервіс | Що пропонує | Описи подій і межі порівняння |
|---|---|---|
| CrimeRate, Велика Британія | API статистики територій; місячні пакети запитів; окремі географічні вибірки у файлах | Сайт і API використовують спільний набір. Перевірена сторінка описує статистику, не перевірені перекази судових рішень |
| CrimeoMeter | Комерційна підписка; API окремих подій, статистики й карт; окремий продукт CSV | Приклад відповіді має ID, дату, категорію, короткий опис, джерело, адресу й координати; судового документа чи перевіреної судової фабули приклад не містить |
| SpotCrime | Комерційний/дослідницький доступ за зверненням | Офіційний опис API: стандартизована подія, місце, джерельне посилання й опис від поліції. Стаття 2019 року; актуальний тариф не підтверджений |
| data.police.uk | Офіційний API подій та результатів | Структуровані категорії, місяць, приблизне місце, результат; context може бути порожнім. Це не комерційний аналог і не доказ наявності розгорнутих фабул |

Джерела:

- [CrimeRate API та вибірки](https://crimerate.co.uk/crime-data-mcp-api):
  оприлюднені пакети £28–£1 300/місяць без ПДВ; початковий £28 за 500
  кредитів. Один запит статистики — один кредит. Ціни зафіксовані на дату
  перевірки, не орієнтир ціни українського продукту. Сторінка обмежує
  публікацію отриманих даних на загальнодоступних сайтах без окремого погодження.
- [CrimeoMeter: приклад API подій](https://www.crimeometer.com/crime-data-api)
  та [підписки](https://www.crimeometer.com/pricing). На відкритій сторінці
  ціни комерційного пакета не наведені; посилання на плани не замінюємо
  здогадкою про суму.
- [SpotCrime: офіційний опис API від 04.03.2019](https://blog.spotcrime.com/2019/03/the-spotcrime-api.html)
  та [джерела даних](https://spotcrime.com/about).
- [data.police.uk: схема відповіді](https://data.police.uk/docs/method/crime-street/).

Публічні схеми не розкривають внутрішню структуру чужих баз. Не робимо
висновку, що в них рівно два чи три внутрішні тексти. Не знайшли в цих
джерелах підтвердження автоматичного виготовлення перевірених фабул із
судових рішень. Їхні поліцейські повідомлення не рівнозначні нашому корпусу
підтверджених судом епізодів. Рейтинги небезпеки й прогнозування не запозичуємо.

## Що рекомендуємо для нашого продукту

Три майбутні способи доставки тих самих дозволених даних:

1. API подій: фільтр території, періоду й категорії; дата/точність,
   фабула, джерела, статус і дата перевірки.
2. API статистики: кількості та динаміка з покриттям, базою порівняння
   й обмеженнями. Без балів небезпеки й заяв про причинність.
3. Ліцензована вибірка: за територією/періодом у CSV або іншому погодженому
   форматі, з версією, описом полів та правилами застосування відкликань.

Це варіанти майбутнього B2B — продажу організаціям, а не три нові функції MVP.
Коло потенційних покупців і готовність платити ще не перевірені. API не
змінює FREE/PRO: базова карта й фабули лишаються у FREE.

Сенс оплати — підготовка й перевірка даних, зручність отримання, регулярність
оновлень і підтримка. Не стверджуємо виключного права на відкриті факти.
Правила джерела, зміст ліцензії та конкретна зовнішня видача потребують
перевірки до продажу. Приватні виключення й приховування координат діють
також у платному наборі. Комерційне оформлення — за правилом партнера з AGENTS.

## Що закласти зараз, що зробити пізніше

Зараз: сталі ID подій; документ→епізоди→джерела; версії; контроль дублів;
два тексти; докази фактів; категорії; розділення невідомого й перевіреного;
обсяг покриття; відкликання; відокремлення внутрішніх і зовнішніх даних.

Після малого контролю й пілота: перевірений випуск; імпортери карт;
постійний сервер і відновлення резервної копії; виміряна точність фабул,
місць та відстеження скасувань. Після перевірки попиту — API з ключами,
лімітами, версіями, умовами використання та обліком запитів.

Повнота означає відомий відсоток отримання й обробки визначеного корпусу,
а не всі правопорушення міста. Повні джерельні файли зберігаються приватно;
покупцю не видається необроблений внутрішній архів за замовчуванням.

Реалізація й фактичні результати малого контролю ведуться в
[спільній базі](https://github.com/Andriithis/dani-edrsr/blob/main/docs/0002-fabula-i-data-product.md).
