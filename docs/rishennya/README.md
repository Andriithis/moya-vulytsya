# Записані рішення

Кожне велике рішення — окремий файл. Не «ми вирішили X», а: що вирішили, чому,
що ще розглядали, і за яких умов рішення варто переглянути.

**Навіщо.** Через півроку ніхто не пам'ятає причин. Без цих файлів одні й ті
самі питання переобговорюються по колу, а нові учасники (люди або ШІ) не
розуміють, чому зроблено саме так, і починають «покращувати» вже вирішене.

## Формат

```markdown
# NNNN. Назва

**Статус:** прийнято / відкрито / переглянуто / скасовано
**Дата:**

## Питання
Що саме вирішуємо.

## Рішення
Що вирішили.

## Чому
Обґрунтування.

## Що ще розглядали
Альтернативи і чому не вони.

## Наслідки
Що це змінює в роботі.

## Коли переглянути
За яких умов рішення варто змінити.
```
