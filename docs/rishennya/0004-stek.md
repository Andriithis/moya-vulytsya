## Варіант А — стандартний шлях

| Частина | Технологія | Чому |
|---|---|---|
| Конвеєр | Python | у ньому вже написаний старий прототип; найкращі бібліотеки для роботи з текстом і геоданими |
| База | PostgreSQL + PostGIS | безкоштовна; PostGIS — стандарт для географії, вміє «що в радіусі», соти, перетини зон |
| API | FastAPI (Python) | та сама мова, що й конвеєр — не треба двох стеків |
| Сайт | MapLibre GL | безкоштовний рушій карт, без прив'язки до платного постачальника; вміє соти й 3D |
| Сервер | звичайний VPS, ~$10–20/міс | достатньо на кілька років |

**За:** усе безкоштовне, все стандартне, величезна кількість документації й
прикладів, легко знайти людину на допомогу.
**Проти:** треба самим адмініструвати сервер і базу.

## Варіант Б — менше адміністрування

Те саме, але база — керована (Supabase, Neon або аналог): база в хмарі, ніхто
нічого не налаштовує.

**За:** менше роботи з інфраструктурою, є готова авторизація.
**Проти:** плата з обсягу; на великих просторових запитах може вийти дорого;
залежність від постачальника.

## Варіант В — спершу простіше

Конвеєр на Python, дані в SQLite з просторовим розширенням, сайт статичний.
Перехід на PostgreSQL — коли впремося.

**За:** нічого не треба піднімати, працює на ноутбуці.
**Проти:** переписувати доведеться майже все, і саме тоді, коли з'являться
користувачі. Часова машина й моніторинг на цьому не будуються.
