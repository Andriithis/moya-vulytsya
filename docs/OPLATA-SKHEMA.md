# Як підключиться оплата — схема (ZAVDANNYA-85)

Зараз оплати немає: кнопки «Довідка — 199 грн», «3 довідки — 449», «Повний звіт — 599», підписка, ОСББ і бізнес ведуть на
`/oplata/?tovar=…` — сторінку «Оплата скоро, залиште пошту» (форма передзамовлення заглушки). Тут — як буде, коли партнер
підключить платіжний сервіс. **Ключів і назв рахунків тут немає й не буде** (AGENTS.md, розд. 13); усе про платежі,
договори й клієнтів — на партнері (AGENTS.md, розд. 11; `docs/02-pravo.md`, розд. 6).

## Кроки

```
Сторінка будинку / вітрина
   │  кнопка «Довідка — 199 грн»  →  /oplata/?tovar=dovidka&budynok=/budynok/<вулиця>/<номер>/
   ▼
Наш сервер (партнера): створює замовлення {товар, будинок, ціна з TSINY, пошта}
   │  запит до платіжного сервісу партнера (ключ — лише змінна середовища на сервері)
   ▼
Сторінка оплати сервісу (картка, Apple/Google Pay)  →  повернення на /oplata/dyakuiemo/?zamovlennia=<id>
   │
   ▼
Сповіщення сервісу на наш сервер (підписане)  →  сервер перевіряє підпис і суму
   │  оплачено  →  генератор довідки (dani-edrsr/src/zvit/, режим --dovidka чи --povnyi) → посилання на пошту
   ▼
Підписка: щомісячне списання сервісом; сервер рахує довідки місяця (1 включена, далі по 99; рієлтору 5)
```

## Правила

- Ціна береться лише з однієї таблиці (`site/storinky_mv100.py`, `TSINY`) і перевіряється на сервері — не з адреси сторінки.
- Сайт лишається без сервера (файли під Cloudflare Pages); сервер потрібен лише для замовлення, сповіщення й видачі довідки.
- Описи подій і рішення віддає лише сервер після перевірки оплати (AGENTS.md, розд. 8); у публічних файлах — лише числа.
- Повернення грошей, рахунки ОСББ (юрособа), оферта — на партнері.

## Що треба від партнера

1. Обрати платіжний сервіс (з регулярними платежами для підписки й рахунками для юросіб).
2. Договір із сервісом на себе; ключі — лише на сервері.
3. Оферта з цінами MV-100 (зараз в оферті заглушки — 690 грн за аналіз, MV-11: оновити).

Не перевірено: умови й комісії конкретних сервісів — не порівнював.
