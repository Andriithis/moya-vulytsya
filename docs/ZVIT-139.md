## 3. Справжня карта сайту проти рушія

Записано сторінку карти, зібрану з того самого випуску 08.11 (`video/vau/zapys139.py`): весь кадр, увімкнено 3D, камера
летить тими самими ключами, що й кліпи рушія. Стиснення переносить добре (схожість 0,98).

| | Справжній сайт | Рушій |
|---|---|---|
| Довіра | **вище:** видно, що це справжній продукт — пошук, кнопки, шкала часу | намальовано, «рекламний» вигляд |
| Карта | соти дрібні й бліді, 3D — лише вершини; добре видно вулиці | соти, стовпчики, теми — як захочемо |
| Чистота кадру | ≈ чверть кадру займають меню, пошук, нижня панель; під час руху вискакують підказки («Детектив тижня», райони) | нічого зайвого, текст великий і там, де треба для TikTok |
| Текст | дрібний (вигляд телефона 540 px); з телефона в стрічці не читається | великий, кінетичний |
| Керування | сайт живе своїм життям (шкала місяців сама перемикається) — кожен запис трохи інший | кадр за кадром однаковий |

**Висновок:** для «вау» і гачків рушій кращий — чистіший і керованіший. Запис сайту — там, де головне «це справжній сайт»:
«Як це працює», «POV: застава завтра», продуктові ролики. Для таких записів варто приховати підказки сайту
(«Детектив тижня», вибір районів) параметром запису — зараз не зроблено.

## 4. Порада: топ-8 для тесту й чому

1. **«Плитка»** — найчистіший кадр, нічого не «їсть» соти, найкраще пережила стиснення серед карт. Відповідь на В1.
2. **Стовпчики, що ростуть** — рух сам тримає перші 3 секунди; після стиснення майже без втрат.
3. **Теплова пляма** — «де густо» зрозуміло без пояснень; зовсім інша картинка, ніж соти (В2).
4. **Тонкі 3D-шпилі** — найбільше «вау» серед адрес, видно і «ліс», і окремі піки; адреси без номерів (В3).
5. **Соняшник подій** — одне публічне місце, сотні подій по одній; добре для «Адреса зблизька».
6. **«Годинник» доби** — не карта, читається з першого погляду, стиснення не шкодить; пара для «День і ніч».
7. **Календар року** — готовий вигляд для типу «Календар року» з реєстру; великий контраст до карт.
8. **Тема «Монохром з акцентом»** — погляд одразу йде в одне місце; найлегше показати «тут більше даних» без «страшно».

Запасні: бульбашки з числом (для ігор «вгадай»), інфографіка, «Над дорогами» (коли треба «як на сайті»), тема «Нічне місто».
