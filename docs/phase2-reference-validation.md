`pipeline.osm_boundary` звіряє ID, назву, admin_level, boundary, Wikidata;
збирає кільця за спільними ID вузлів, а не приблизною відстанню. Розриви,
розгалуження та невідомі геометричні члени не виправляє навмання.
Результат: 1 полігон, 3 кільця (зовнішнє + 2 отвори). Самоперетинів не
виявлено; адміністративний центр relation потрапляє всередину.

Збережено похідну геометрію у `config/geocoding/kyiv_boundary.geojson` разом
із джерелом, версією, хешем, автором перевірки та attribution ODbL.
Це межа OpenStreetMap, а не офіційний кадастровий документ. Структурна
перевірка не встановлює точність кожної ділянки межі. Незалежна перевірка
спірних ділянок залишається відкритою.

Відтворення зі збереженого приватного XML:

```text
python -m pipeline.osm_boundary --source private/reference/kyiv-relation.osm --output private/reference/new-boundary.geojson --reviewed-at 2026-09-15
```

## Перейменування

Джерело: [офіційний перелік КМДА 2014–2025](https://minio.kyivcity.gov.ua/kyivcity/sites/21/uploaded-files/Perelik%20pereimenovanykh%20u%202014-2025%20rokakh%20vulyts%20mista%20Kyieva.pdf).
SHA-256 PDF: `e7ecaf723d144dffaf3203d96a38e773782c5c05788a704e4dfc1d2a0087cbd1`.
Перевірено таблиці та зображення сторінок 1 і 10; повторні згадки звірено по
всьому документу. Початковий довідник має 4 пари:

- Мельникова → Юрія Іллєнка;
- Тельмана → Німецька;
- Тверська → Єжи Ґедройця;
- проспект Червонозоряний → проспект Валерія Лобановського.

Це частковий перелік, не повна нормалізація всіх історичних назв. Ініціали,
зокрема «Ю. Іллєнка», не розгортаються автоматично.

Відомо неоднозначні старі назви **Червоноармійська, Горького, Максима Горького**
заблоковано: у різних районах це різні перейменування. Навіть один знайдений
будинок у неповній OSM-базі не знімає неоднозначність. Для їх підтримки потрібен
доказовий район/географічний контекст, якого поточний кандидат не гарантує.
Політика `kyiv-exact-house-v2` та хеш списку блокувань відкликають старий кеш.
