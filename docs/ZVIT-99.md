## Андрію — коротко

- **Продаж готовий до ввімкнення.** Коли партнер дасть платіжний сервіс, ключі й сервіс листів — 10 кроків
  ([`docs/PRODAZH-SERVER.md`](docs/PRODAZH-SERVER.md), розд. 7), кілька годин роботи. Доти сайт не змінюється: «Оплата скоро».
- **Як працює:** людина на сторінці будинку тисне «Довідка — 199», лишає пошту, платить у сервісі; за 1–3 хвилини
  отримує лист із посиланням на довідку. Підписка, «3 довідки», ОСББ, рієлтор — теж. Кабінет — вхід без пароля, за
  посиланням на пошту: мої довідки, «Стежу», скасувати підписку, видалити мої дані.
- **Платіжний сервіс — порада: LiqPay**, запасний — plata by mono (дешевший, але підписку ще треба звірити). Обидва
  підключено «перехідниками» — замінити сервіс = одна змінна. Є тестова оплата без грошей для перевірки.
- **Безпечно:** ціну не підробити (бере лише з нашої таблиці), чужу довідку не відкрити, описи подій — лише після оплати.
  Номера картки ми не бачимо.
- **Одна річ потребує машини:** генератор довідки — програма з гігабайтами даних; вона працює окремо («видавач»), найпростіше
  — на сервері партнера. Рішення — центрального чату.

## 2. Тести

- `site/worker/testy/prodazh.test.mjs` — **17 тестів** (Node 22, справжня схема `skhema.sql` у SQLite): ціна з форми
  й адреси не підробляється; сповіщення з іншою сумою нічого не видає; бізнес / «додаткова» без підписки / неіснуючий
  будинок / форма з чужого сайту — відмова; повний шлях оплата → черга → лист → довідка; **чужий не відкриє чужу довідку**
  (6 способів); підпис і повтор сповіщення; тестова оплата лише з обома змінними; видавач: 3 невдачі, повернення в чергу
  за 30 хв; підписка (додаткова 99, нове списання, скасування); рієлтор 5, ОСББ свій будинок, пакет 3; вхід у кабінет;
  «Стежу» й видалення даних; прибирання; LiqPay (sha1, sha3-256), mono (ECDSA); SHA3 на JS = node:crypto.
- `tests/test_prodazh.py` — таблиця цін сервера = `site/tsiny.py`; у коді сервера немає сум і ключів; запуск тестів Node;
  **наскрізно** місцевий сервер → замовлення → тестова оплата → `vydavach.py` (генератор — підміна) → лист → довідка.
- `tests/test_sait.py` — оновлено перевірку `wrangler.jsonc` (адреси продажу; без `--prodazh-d1` продаж вимкнено).
- Перевірки GitHub: додано Node 22 у `.github/workflows/test.yml`, щоб тести Workers не пропускались.
- Тести ловлять навмисні помилки: вимкнена перевірка суми → падає тест суми; «будь-яка сесія відкриває будь-яку довідку»
  → падає «чужий не відкриє».
- Справжній рушій Workers локально (`wrangler dev --local`, wrangler 4.163): замовлення, тестова оплата, кабінет;
  підписи LiqPay sha1 і sha3-256 і mono — правильні 200, підроблені 403. `wrangler deploy --dry-run` збирає скрипт.

Усі тести продукту: `python -m unittest discover -s tests` — зелені (пропуски — лише браузерні перевірки без Playwright).

## 3. Що не перевірено (чесно)

- Справжні LiqPay і mono — немає ключів. Поля підписки LiqPay — зі сторонніх описів (офіційна сторінка не відкрилась).
  Чи приходять щомісячні списання LiqPay з тим самим номером замовлення — від цього залежить продовження підписки.
  Документація LiqPay сама собі суперечить щодо алгоритму підпису (sha3-256 у тексті, sha1 у прикладах) — є змінна.
- Справжній генератор через видавача — у хмарі немає даних (OSM, 1551). Адреса для генератора — із заголовка сторінки
  будинку («вулиця Жилянська, 5»); що ключ адреси її розбирає — перевірено на 4 прикладах (`adr_kliuch`), не на всіх будинках.
- D1, R2, розклад прибирання й листи — не на акаунті Cloudflare. Межі безкоштовних планів D1/R2 — не перевіряв.
- Строки зберігання замовлень — юрист і бухгалтер партнера.
- Вигляд сторінок кабінету — не дивився в браузері (класи сайту, без знімків).

## 4. Питання — центральному чату / Андрію

1. **D1 замість Supabase для замовлень** (розд. 8 `PRODAZH-SERVER.md`): той самий акаунт Cloudflare, база ззовні
   недосяжна, без призупинення простою. Supabase для карти підписника (MV-40) не зачеплено. Потрібне рішення MV.
2. **Де працює видавач:** порада — сервер партнера (служба, що сама перезапускається). Це виняток із «сервер партнера — ні»
   (MV-105) лише для генератора.
3. **ОСББ:** прийняв «рік, 1 довідка на місяць лише на свій будинок, без додаткових». Так?
4. **Рієлтор понад 5** — «додаткова» по 99, як у звичайній підписці. Так?
5. **Сервіс оплати:** порада LiqPay; вибір і договір — партнера.
