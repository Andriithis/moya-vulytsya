# Знімки й запис прототипу «Літопис міста» (ZAVDANNYA-140)

Пробний випуск 08.11 і колода гри; Подільський район. `pk-*` — ПК 1280×800 (×2), `tel-*` — телефон 390×844.
Кольори знімків зменшено до 256, щоб не роздувати репозиторій.

| Файл | Що |
|---|---|
| 01-start | «Де ви живете?» — вибір району |
| 02-pershi-dotyky | після 12 дотиків: межа району, кружечки вулиць |
| 03-persha-vulytsia | перша вулиця відкрита: числа, події з колоди, посилання на рішення, нові картки |
| 04-pomichnyky | помічники, множник, «нове видання» |
| 05-kartky | картки видів з рідкістю за справжньою частотою |
| 06-den | «Справа дня»: вид і район (одна спроба) |
| 07-zavtra | що буде завтра і блок підписки (вимкнено) |
| 08-povernennia | наступного дня (`?zsuv=14`): «Поки вас не було…» |
| 09-novyi-den | нова справа дня |
| 10-vulytsi | список вулиць району |

`litopys-telefon.webm` — запис екрана телефона (≈ 1 хв): перші хвилини, відкриття вулиць, «День», повернення.
