## Два правила про цю папку

**Оновлюй `08-stan.md`.** Це єдиний файл, який змінюється постійно. Він потрібний
для того, щоб наступна сесія роботи (або наступний чат з ШІ) почалася не з нуля.

**Велике рішення — окремий файл у `rishennya/`.** Не «ми вирішили Postgres»,
а що саме вирішили, чому, що розглядали ще і за яких умов рішення варто
переглянути. Через півроку ніхто не пам'ятає причин.
