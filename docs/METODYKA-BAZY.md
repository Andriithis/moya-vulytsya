3. **Слабке місце — дати.** Дата коміту в git ставиться комп'ютером автора і її можна підробити. Сильнішими доказами
   є незалежні позначки часу: час push і злиття PR на GitHub, SHA-256 випусків у Release — та, найкраще,
   **кваліфікована електронна позначка часу** на хеш знімка методики. Порада: щомісяця (з випуском) робити знімок

4. **«Пастки» — вигадані події для виявлення копіювання — ні.** Вони суперечать нашому ж правилу «немає джерела — немає

   хеш кожної видачі в журналі (розд. 7). Що з цього можна вписати в договір — юрист.

## 3. Упорядкування

**Подія ≠ проблема.** Подія — окремий випадок; проблема — концентрація повторюваних однотипних подій; причинності не
стверджуємо, рейтингів не робимо (`AGENTS.md`, розд. 2, 4; S-М.2). Проблеми — нічний аналітик за правилами карти Києва
(MV-36: мв:bbd4ced, дані:9d2384f — 09.11). Звіт — без прогнозу й без тверджень про зв'язки між видами (MV-66:
мв:cb63883, дані:df2370d — 14.11; S-М.18).

**Три рівні інформації — схема даних.** Факт — з посиланням на рішення; сигнал — з періодом, територією й базою
порівняння; гіпотеза не має координат і в випуск не входить (`AGENTS.md`, розд. 6; S-М.4). Схема випуску —
`dani-edrsr/db/vypusk.sql` (з 06.11, дані:21866f0; 6 змін), номер події `<справа>|<вид>` (MV-44: дані:e7e9cc9 — 11.11).

**Групи.** Власна система груп подій — сім груп (MV-116: мв:a9dcdaa — 17.11; дослідження MV-115: мв:dda6fd6); групи
скарг 1551 «для людей» (`config/1551-hrupy.csv`, MV-80: дані:f2f9c1f — 15.11); ціль = об'єкт посягання для всіх видів
(MV-65: мв:cb63883, дані:9587a64 — 14.11; MV-72, MV-73).

**Місце.** Точка — точний будинок, перехрестя або назване місце, як у карті Києва (S-М.1; MV-35); назване місце — точка
на самому об'єкті (MV-54); адреса проживання — не місце події, крім дії в самому житлі (S-Ч.4; MV-20: мв:cd61900 —
08.11); місце з інших рішень тієї ж справи (S-М.5; MV-47); перейменування вулиць — власна таблиця
(`config/pereimenuvannia-kyiv.csv`, S-М.10); тип вулиці в ключі адреси (MV-77: мв:fd909e8, дані:c989eba — 15.11); номер
з літерою й дробом (MV-81: мв:db54080, дані:0a05bc1); «точка є — назва є», таблиця місць (MV-117: мв:154ea98,
дані:9471af5 — 17.11).

**Точність важливіша за повноту.** Показуємо лише те, що визначено надійно; невизначене — не точка, повноту рахуємо
окремо (MV-67: мв:f28393f, дані:997ba7c — 15.11); вулиця без номера — підсумок по вулиці, не точка (MV-68: мв:591920b,
дані:05d7a17 — 15.11). Година — лише якщо прямо є в тексті (MV-67, MV-84).

**Перекази без вигадок.** Фабула для людей — лише через `src/pokaz_fabuly.py` (дані:33968d5 — 08.11; S-П.1): без
процесуального хвоста, «ОСОБА_N» → «особа N», без прізвищ суддів і поліцейських. ШІ переписує, але не вигадує
(`AGENTS.md`, розд. 5; MV-21: мв:7fe92a1 — 08.11); витяг полів ШІ — разом із переказом і дослівною цитатою для кожного поля
(MV-78: мв:50a7dfd, дані:f34839e — 15.11; MV-83, MV-85; S-М.19); на картах — обрізана фабула, перекази — лише у звітах
(MV-110: мв:2866188, дані:8d0287b — 17.11).

**Скарги 1551.** Звернення = повний `uid`, останній рядок; групи для людей; прив'язка до будинків; «звернення, не
перевірений факт» (MV-80; MV-90: мв:239caf8 — 16.11). Порівняння з сусідніми будинками того самого класу поверховості

3. **Депонування / реєстрація.** Державна реєстрація авторського права необов'язкова, але свідоцтво — доказ у суді;
   можна зареєструвати базу як твір (компіляцію) з описом методики. Нотаріус може посвідчити час пред'явлення
   документа (Закон «Про нотаріат», ст. 34 — **не звірено з чинною редакцією**). Що з цього варте грошей — юрист.
4. **Договори з компаніями.** Доступ до бази — користування на строк, не продаж (`AGENTS.md`, розд. 8); заборона
   передачі й перепродажу, журнал видач, право перевірки; комерційна таємниця на алгоритми (`docs/02-pravo.md`, розд. 5).
5. **Торговельна марка** на назву — єдиний надійний бар'єр (`docs/02-pravo.md`, розд. 5).

## 7. Водяні знаки в даних для компаній — чи можна «пастки»

| Спосіб | Чи можна | Чому |
|---|---|---|
| **Вигадані події** («пастки», як вигадані вулиці на картах) | **ні** | суперечить «немає джерела — немає факту» (`AGENTS.md`, розд. 5–6): кожна подія — з посиланням на рішення; клієнт купує факти, а вигадка може потрапити в його продукт і нашкодити людям; ризик за ст. 302 ЦК (недостовірна інформація) |
| Вигадані адреси в довіднику адрес | ні (те саме) | адреса без будинку — теж вигаданий факт |
| **Окремий для клієнта порядок рядків і службові номери** (`event_id` клієнта — шифр від справжнього) | так | фактів не змінює; копія видає, чия вона |
| **Контрольна службова таблиця** з кодом клієнта й датою видачі, названа в договорі | так | відкрито, не факт про місто |
| Зсув координат у межах заявленої точності (≈ 1 м на точку будинку) | обережно, лише з договором | формально змінює дані; якщо так, — сказати в договорі, що координати мають позначку |
| Хеш кожної видачі й журнал «кому, що, коли» | так | доказ, що саме цей файл видано цьому клієнту |

Порада: перші три «так» — достатньо для виявлення копії; вигаданих подій не робимо.

## 8. Як відтворити посилання

```
# коміт і дата, якими вперше записано MV-N
git log --reverse --format='%h %ad' --date=short -S "## MV-N." origin/main -- RISHENNYA.md | head -1
# перший коміт і кількість змін файлу
git log --reverse --format='%h %ad' --date=short origin/main -- SPECYFIKATSIYA.md | head -1
git log --format=%h origin/main -- SPECYFIKATSIYA.md | wc -l
```

Клон має бути повним (`git fetch --unshallow`), інакше історія обрізана.
