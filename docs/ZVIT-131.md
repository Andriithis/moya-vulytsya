## Автопостинг без сервера — головне

- **Чому GitHub, а не Cloudflare:** на безкоштовному Cloudflare кожен запуск має 10 мілісекунд роботи процесора — ролик у
  YouTube так не завантажити, і код довелося б переписати. GitHub запускає наш код як є.
- **Де працює:** у **приватному** репозиторії Микити (організація `moyavulytsya`). Не в нашому `moya-vulytsya`: він
  публічний — журнали запусків і стан бачив би кожен.
- **Скільки коштує:** 0. Приватному репозиторію GitHub дає ≈ 2 000 хвилин на місяць; нам треба ≈ 400.
- **Що в хмарі не вийде:** TikTok (його ключ змінюється щоразу, зберегти його між запусками без ще одного сильного ключа
  не можна; до перевірки TikTok однаково публікує лише «бачу тільки я») — Микита ставить ролики сам. Instagram — лише
  коли ролики лежатимуть за публічною адресою (порада — безкоштовне сховище Cloudflare R2; не зроблено). X у нашому
  автопостингу немає.
- **Звідки дані:** з приватного Release `dani-edrsr` (файл `avtopostynh-vkhid-<дата>.zip`). Ключ лише на читання
  створюєш ти й сам вписуєш його в секрет на зустрічі. **Скрипта, що пакує цей файл, ще немає** — це крок разом із
  роликами (ZAVDANNYA-129).

## Чесно: що не перевірено

- **Жодного запуску на самому GitHub.** Перевірено в хмарі: файл розкладу читається; команди запуску (пробна година,
  «прибрати», «відновити») працюють; без даних і не в пробному режимі запуск сам зупиняється. Запис стану в гілку
  GitHub і завантаження з Release — не перевірено (тут немає ні приватного репозиторію, ні ключів). Інструмент перевірки
  файлів розкладу (actionlint) завантажити не дали — перевірено лише читанням.
- **Імена в Instagram і Facebook** — не перевірено; **Gmail** — перевіряється лише при реєстрації; X — «ймовірно».
  Між перевіркою й реєстрацією ім'я може хтось зайняти.
- **Ціни:** nic.ua — зі сторінок 19.11 без особистої знижки, ПДВ не вказано; `.com` у Cloudflare — ≈ 10–11 $ за
  сторонніми оглядами. Безкоштовні хвилини GitHub з 28.10.2026 рахуються як 12 $ на місяць — теж за сторонніми
  оглядами, офіційну сторінку не відкрив.
- **Категорії** TikTok і Facebook — назви в застосунках не перевіряв, написано «найближча до…».
- Чи можна «Прибрати» з застосунку GitHub на телефоні, а не з браузера, — не перевірено.
- Перші 9 дописів — **план**: жоден ролик ще не готовий (перемонтаж і голос — ZAVDANNYA-129).
