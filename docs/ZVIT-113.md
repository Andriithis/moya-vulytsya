## Коротко для Андрія

Тепер для будь-якого публічного місця (площа, вокзал, метро, ТЦ, ринок, парк) програма сама робить безкоштовний візуал для
журналістів:
- картку 1:1 і 16:9;
- 8 слайдів, разом і одним PDF.

Підпис «Джерело: Моя вулиця» і посилання на сторінку місця стоять на кожному кадрі. На сторінці місця з'являється блок «Для
медіа»: картка, три кнопки «завантажити» й умови. Перший справжній візуал — Вокзальна площа: **401 подія в колі 300 м, у
типовому такому колі Києва — 51**. Для житлового будинку візуал не робиться: програма зупиняється з помилкою.

## Чесно про числа й межі

- **Чутливі справи.** У прототипі виключались усі чутливі. Тепер — як на відкритих сторінках (MV-102): домашнє насильство
  рахується. Число Вокзальної від цього не змінилось (401).
- **Сторінки місць є лише для площ.** На сайті є сторінки вулиць, площ, будинків і районів, а окремих сторінок станцій
  метро, ТЦ і ринків немає. Тому кнопка зараз можлива лише на сторінках площ (їх на сайті 32), а візуал зроблено лише для
  Вокзальної. Генератор уміє й метро, ТЦ, ринки: досить рядка в `config/mistsia-media.csv`, коли в них з'явиться сторінка.
  Без сторінки візуал не робиться, бо посиланню нікуди вести (KOMPAS, розд. 0).
- **Два різні числа на одній сторінці.** Сторінка площі рахує події з адресою «Вокзальна площа» за 2024–2026 (255). Візуал
  рахує всі події в колі 300 м (401). Блок «Для медіа» прямо пише «у колі 300 м», але людина може їх зіставити.
- **Людне місце завжди «більше».** На слайді 2 поруч є рядок «де більше людей — там більше подій у даних. Число — не оцінка
  місця».
- **Готові візуали — результат збирання**, як колода гри: у git їх немає, сайт бере теку параметром `--media`. Перший
  справжній збережено в `docs/znimky-113/` для перегляду й тестів.
- **Домену немає.** Посилання на картинці — умовна адреса `moya-vulytsya.pages.dev/…`. Після вибору домену візуали треба
  перемалювати однією командою.

## Як зробити візуал

```
python dani-edrsr/src/vizual_mistsia.py events-<дата>.db <тека чисел>                 # усі місця з config/mistsia-media.csv
python moya-vulytsya/brend/media/zrobyty_media.py <тека чисел>/vokzalna-ploshcha.json <тека media>/vokzalna-ploshcha
python moya-vulytsya/site/zibraty_sait.py events-<дата>.db <сайт> … --media <тека media>
```

Числа — ≈ 2 с на місце. Картинки й PDF — ≈ 10 с, потрібні Playwright і Chromium (`MV_CHROME` — шлях до іншого Chromium).

## Що не перевірено

- Повний сайт з `--media` на справжньому випуску не збирав. Сторінку Вокзальної площі зібрав окремо тією самою функцією
  (знімки `dlia-media-*`). Копіювання теки на сторінку в повній збірці тестом не покрито: у штучному місті тестів немає площі.
- Як картки виглядають у чужих статтях і соцмережах (обрізання, стиснення) — не перевіряв.
- Попит редакцій — не перевірено (як і в NOVI-LINII.md).
- «Типове коло» — медіана 2 814 кіл по всьому Києву. Інша база (лише людні місця чи свій район) дасть інше число.
