# ЗВІТ-132 — Сайт до запуску: режим «скоро», MV-155, викладка на Cloudflare

Виконавець — хмара, 19.11.2026. Завдання — `ZAVDANNYA-132.md`. Нічого не опубліковано й не викладено.

## Коротко для Андрія

1. **Сайт готовий до викладки одним запуском.** Микита запускає одну команду (або кнопку в GitHub) — сайт збирається,
   викладається на Cloudflare з доменом і сам себе перевіряє. Перевірив на **справжньому пробному випуску 08.11**:
   зібрався без жодної правки коду (1 491 вулиця, 1 033 адреси для Google). Повний Київ 21.11 — та сама команда.
2. **Поки немає оплати — режим «скоро».** На кожній кнопці оплати під ціною — «Скоро — залиште пошту». Людина лишає
   пошту, а ми зберігаємо, **що** вона хотіла купити і **для якого будинку**. Коли Микита підключить LiqPay — міняє один
   перемикач і вписує ключі; кнопки, ціни й оплата вже готові.
3. **MV-155 зроблено:** П4 — розділ «Рішення, що ще не набрали законної сили» на сторінці «Як ми працюємо з даними»;
   П6 — без галочки «Прошу надіслати одразу; після надсилання відмовитися не можна» оплатити не можна (і в кабінеті теж);
   П7 — лист ОСББ за 3 дні до річного списання йде сам, раз на рік, скасованим — ні.
4. **Покроково для Микити — [`docs/ZAPUSK-SAITU.md`](ZAPUSK-SAITU.md):** ≈ 40 хвилин підготовки раз, далі — одна команда.
   Там же 10 пунктів «що перевірити після» (6 скрипт перевіряє сам) і як увімкнути оплату.
5. **Перевірка на телефоні:** 29 сторінок (усі види) — відкриваються, нічого не вилазить убік, помилок немає.
   Головна на повільному мобільному інтернеті: текст — за 1,6 с, карта — ≈ 11 с без стиснення (Cloudflare стискає
   в ≈ 3,5 раза — тоді, за оцінкою, ≈ 4–5 с; не міряно на Cloudflare).
6. **Одне рішення для центрального чату:** форми сайту (передзамовлення, звернення, «скоро», чотири числа) я поклав у базу
   **Cloudflare**, а не в Supabase, як каже MV-8. Причини нижче. Старий шлях не видалено.

## Що зробити Микиті

Усе — у [`docs/ZAPUSK-SAITU.md`](ZAPUSK-SAITU.md). Коротко, раз:
1. Пошта на домені: отримувати — Email Routing у Cloudflare; надсилати з сайту — Resend (без нього звернення треба
   дивитися вивантаженням щодня).
2. Токен Cloudflare (шаблон «Edit Cloudflare Workers» + право D1), база D1 однією командою, токен лічби відвідувань.
3. Файл зі своїми даними для оферти (9 рядків, зразок є).
4. Запуск: спершу «сухо» (нічого не змінює), потім справжній. Після першої викладки — секрет `ADMIN_KLIUCH`.
5. Від тебе: покласти в Release разом із повним Києвом `budynky-*.json` — **без нього немає сторінок будинків**
   (у пробному Release 08.11 його немає, тому там сайт без будинків).

## Рішення для центрального чату: форми — у Cloudflare, а не Supabase (MV-8)

- **Чому:** Supabase-проєкту немає в пакеті акаунтів 20.11 (`AKAUNTY-PAKET.md`), а збирач сайту досі клав форми **без**
  адреси сховища — тобто на запуску передзамовлення й **звернення «прибрати подію»** не працювали б взагалі. Безкоштовний
  Supabase «засинає» після тижня тиші (ризик MV-8). База Cloudflare D1 — той самий акаунт, що й сайт (вже потрібна для
  продажу, MV-140), ззовні недосяжна, ключа в сторінці немає.
- **Що лишилось як було:** без бази D1 (варіант Pages) форми йдуть у Supabase, як раніше.
- **Що не переписано:** перевірка форм двічі на добу з GitHub (MV-8, `.github/workflows/perevirka-formy.yml`) перевіряє
  Supabase. Під D1 скрипт викладки перевіряє форму при кожній викладці; щоденну перевірку — окремим завданням, якщо так.
- Потрібен запис MV і, якщо приймете, — позначка «замінено» в MV-8.

## Чесно: що не перевірено

- **Нічого не викладалось на справжній Cloudflare** — немає акаунта й токена. Не перевірено: права токена для D1 і
  домену, прив'язку домену, створення таблиць на сервері, секрети, розклад (лист ОСББ) на Cloudflare.
- **Листи не надсилались** (Resend — за документацією). LiqPay пісочниця (`sandbox = 1`) — за документацією, без ключів.
- **Лічба відвідувань** — що скрипт Cloudflare не заблоковано захистом сторінок, перевірено лише в тексті сторінок, не в
  браузері зі справжнім токеном.
- **Файл для GitHub** (`site/github/vyklasty.yml`) — жодного запуску на GitHub.
- **Сторінки будинків на справжніх даних** — у пробному Release немає `budynky-*.json`; будинки перевірено на штучних.
- Текст П4 («людина вважається невинуватою, доки рішення не набрало законної сили») — мій, без юриста (MV-152).
