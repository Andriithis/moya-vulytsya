# Безкоштовна карта: «вау» і період «роки · місяці» — варіанти (ZAVDANNYA-105)

Хмара, 17.11.2026. Прототип — гілка `ccr-1b1e79ab-w9kba5-105` (код карти `site/sait/karta.js`, `sait.css`; збирач —
місяці в `site/sait/dani.py` і `site/zibraty_sait.py`). **Вибір — Андрія**; до «так» нічого не зливається в робочий сайт
як рішення.

## Висновок

1. **Порада: «вау» 2 «Роки оживають» + смуга «роки · місяці».** Це один механізм (числа по місяцях), тож дає дві речі
   одразу: перший погляд «місто наливається подіями з січня 2024» і інструмент, яким людина потім гортає час. Для роликів —
   найкраще: 6 секунд, що самі розповідають історію, і лічильник «листопад 2024 · 13 995 подій з січня 2024». Ризик —
   читати як «стає гірше»; зростання тут — це лише накопичення справ (див. «Чесність»).
2. **«Вау» 1 «Місто проступає»** — найдешевше й найспокійніше (хвиля від центру, вершини виростають і пружинять, ≈ 1,7 с).
   Нових даних не треба. Якщо обирати один «вау» для щоденного входу — цей: не заважає, не затримує.
3. **«Вау» 3 «Де ви живете?»** — ряд районів унизу; натиск — переліт із нахилом до свого району, вершини району по черзі
   «натискаються». Найбільше веде до продажу (людина одразу на своєму місці → сторінка будинку, MV-106), але це не
   «вау» першого екрана, а запрошення. Добре поєднується з 1 чи 2.
4. **Можна разом:** 1 щоразу на вході (коротко), 2 — кнопкою ▶ у смузі й у роликах, 3 — після 1 як запрошення.
   Порада для першого кроку — **2 + смуга + 3**, а 1 — якщо 2 здасться задовгим.

**Що не перевірено:** дані прототипу **штучні** (справжній випуск — приватний Release, хмара його не завантажує): 40 000
вигаданих подій у межах районів Києва, місяці 2024-01 … 2026-10. Вигляд і рух — справжні, числа — ні. Записи екрана
зроблено в хмарі без відеокарти: рух там рваний, тому є й записи «утричі повільніше» (`?tempo=3`, лише для запису). Людьми
не дивилися; на справжньому телефоні — не перевірено.

## 1. Три варіанти «вау»

Усі — без червоного, без «небезпеки», колір — кількість (MV-58, `docs/STYL.md`). Рух — для всіх: якщо в системі
«менше руху», хвиля коротша (≈ 0,6 с), без пружини, переліт ≈ 0,6 с без нахилу й повороту. Будь-який дотик до карти —
одразу звичайна карта. Вмикається в прототипі адресою: `/karta/?vau=1`, `?vau=2`, `?vau=3`.

| | 1. Місто проступає | 2. Роки оживають | 3. Де ви живете? |
|---|---|---|---|
| Що бачить людина | соти з'являються хвилею від центру, вершини виростають і трохи пружинять | лічильник місяців: соти «наливаються» від січня 2024 до сьогодні, вершини з'являються наприкінці | після появи — ряд районів; натиск — переліт до свого району з нахилом, вершини району відгукуються |
| Тривалість | ≈ 1,7 с (після того як намальовано підкладку) | ≈ 5 с (34 місяці × 0,14 с) + 1,2 с паузи | переліт ≈ 2,6 с за натиском |
| Нові дані | ні | числа по місяцях (див. розд. 3) | ні |
| Для роликів | так, заставка | **найкраще** — історія без слів | так, «ваш район» |
| Веде до продажу | ні (впізнаваність) | ні (цікавість, повернення) | **так**: свій район → вулиця → будинок |
| Ризик | майже немає | «стає гірше» (накопичення ≠ зростання) | MV-58 «переліт — лише при пошуку»: тут він теж лише за натиском — як пошук; треба «так» |

## 2. Смуга «роки · місяці»

Як S-К.9 карти Києва (там: «Усі · Рік · Квартал · Місяць», «‹ значення ›», ▶), лише простіше — без кварталу:

```
[ 2024–2026 | Рік | Місяць ]   ‹ червень 2024 ›   ▶   40 000 подій
```

- **«2024–2026»** — як зараз (MV-32: безкоштовно — останні 3 роки). **Рік / Місяць** — показує стрілки «‹ ›» і
  значення; стрілки гортають обраним кроком, на краю даних — неактивні; при зміні кроку лишаємось у тому самому місці часу.
- **▶** — програє місяці (≈ 0,9 с на місяць; при «менше руху» — 1,4 с); будь-який дотик до карти — пауза на тому місяці.
- Фільтр видів («Усі події ▾») і смуга працюють разом; картка соти й «ⓘ» кажуть «за червень 2024» замість «за 2024–2026».
- **Шкала (MV-55)** — частками в межах обраного періоду: місяць виглядає так само «повно», як три роки, змінюється лише
  *де*. Так чесніше для неповних місяців 2026 (рішення ще публікуються). Інший шлях — спільна шкала на всі місяці (тихі
  місяці блідіші) — показує «скільки», але першими «бліднуть» свіжі місяці, і це читається як «стало спокійніше». Порада —
  частками, як зараз.
- Позначки «неповний» немає (як у карті Києва, S-К.9).
- Місце: ПК — внизу зліва; телефон — смуга на всю ширину внизу, у два рядки; під час пошуку ховається.

## 3. Дані: місяці по сотах

У файлі сот — нове поле `m`: `{група: [[номер місяця від січня 2024, скільки], …]}`, лише непорожні місяці. Це **лише
числа** (межа MV-3 «безкоштовно — скільки»), без адрес і описів. **Статеві й щодо дітей — без місяця** (у числі за 3 роки
великих сот вони лишаються, MV-102): мале число за один місяць легше пов'язати з конкретною справою — моє рішення в
прототипі, потрібне «так». Тест — `tests/test_misiatsi.py` (лише числа; сума місяців не більша за число за 3 роки). Розмір на штучних 40 000 подіях (стиснуто, як віддає сервер):

| Рівень | Без місяців | З місяцями |
|---|---|---|
| 7 (≈ 5 км²) | 13 КБ | 47 КБ |
| 8 (≈ 0,7 км²) | 62 КБ | 136 КБ |
| 9 (≈ 0,1 км²) | 423 КБ | 566 КБ |

Порада для справжнього сайту: місяці — **окремими файлами** `soty-N-misiatsi.json`, що вантажаться лише коли людина
торкнулась смуги (або для «вау» 2 — лише рівні 7 і 8, ≈ 180 КБ). Перший екран тоді не важчає. На справжньому випуску
(≈ 72 000 подій з точкою, повний Київ — більше) — переміряти.

## 4. Чесність і правила

- **«Роки оживають» — накопичення, не зростання.** Лічильник пише «N подій з січня 2024», а не «за місяць»; кінець — рівно
  звичайна карта. Поруч у «ⓘ» варто одне речення: «Карта наповнюється, бо справи накопичуються, а не тому, що стає гірше».
  2026 рік ще не весь опублікований — останні місяці додають мало, і це видно.
- Без червоного, без слів «небезпека», без прогнозів (`AGENTS.md`, розд. 4). Вершини — м'ятні, як і зараз.
- Безкоштовно — лише числа по сотах за 3 роки (MV-3, MV-32): місяці не відкривають адрес і подій.
- Переліт (варіант 3) — лише за натиском людини, як пошук (MV-58). Без геолокації: району людини ми не знаємо й не питаємо
  браузер.

## 5. Записи екрана й знімки

Зроблено `tests/znimky_vau.js` (Playwright), дані — `tests/shtuchne_misto.py`. Для кожного варіанта — комп'ютер
1440 × 900 і телефон (iPhone 13), звичайний рух і «менше руху»; для смуги — «Рік» і програвання місяців.
Записи (≈ 30 файлів .webm, ≈ 25 МБ) — не в git (великі) і лише в тимчасовій теці хмарної сесії, тож їх треба відтворити на
ПК командою нижче. У гілці — знімки `docs/znimky-105/` (`*-kadry-povilno.jpg` — 12 кадрів запису, утричі повільніше). Як відтворити:

```
python tests/shtuchne_misto.py tmp/vau/events.db
python site/zibraty_sait.py tmp/vau/events.db tmp/vau/sait
python -m http.server 8105 -d tmp/vau/sait &
node tests/znimky_vau.js http://127.0.0.1:8105 tmp/vau/zapysy            # звичайний темп
TEMPO=3 node tests/znimky_vau.js http://127.0.0.1:8105 tmp/vau/zapysy3   # утричі повільніше — для хмари без відеокарти
```

На ПК з відеокартою рух плавний; у хмарі (програмне малювання) — рваний.
