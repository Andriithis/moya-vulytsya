## Коротко для Андрія

1. **У кожного публічного місця з випуску тепер своя сторінка** `/mistse/<назва>/`: станції метро, ТЦ, ринки, вокзали,
   парки й сквери, пляжі, мости, острови. І покажчик `/mistsia/` за типами. Зупинки, житло й адреси з номером будинку — ні.
2. **На сторінці лише числа:** скільки подій, де суд назвав саме це місце; за групами; за роками; порівняння «тут · у
   типової станції метро» (те саме правило, що в довідці: «більше», «як у типової» або «мало даних»; «менше» — після повного
   Києва); скарги 1551 будинків у колі 200 м — лише теми й числа, без адрес. «Що поруч» не робили.
3. **Посилання місце ↔ вулиця ↔ район:** на місці — найближча вулиця й район; на сторінці вулиці — «Публічні місця біля
   вулиці»; на сторінці району — «Публічні місця району». Гасло «Моя вулиця — що відбувається під боком» — на кожній.
4. **«Для медіа» — на кожній сторінці**, коли зібрано візуал. Ланцюжок — три команди (розд. 2). Генератор тепер знає й пляжі
   та острови.
5. **Для Google:** заголовок, опис, розмітка місця (станція метро, вокзал, ТЦ, парк, пляж, міст — з координатами), хлібні
   крихти, карта сайту. Місце з 1–2 подіями — сторінка є, але не в пошуку (як вулиці).
6. **Знайшов і виправив попутно:** парки й мости з назвою («Голосіївський парк», «міст Патона») збирач вважав вулицями й робив
   їм сторінки вулиць. Тепер назване публічне місце — не вулиця.

**Не перевірено:** на справжньому випуску (у хмарі його немає) — скільки місць і які назви вийдуть на повному Києві, чи
немає дивних підписів. Усе — на штучному місті з 11 названими місцями.

## 2. «Для медіа» для всіх місць — три команди

```
python moya-vulytsya/site/sait/mistsia.py --baza events-<дата>.db --vykhid mistsia.csv
python dani-edrsr/src/vizual_mistsia.py events-<дата>.db vizual/ --mistsia mistsia.csv
python moya-vulytsya/brend/media/zrobyty_media.py vizual/ media/
python moya-vulytsya/site/zibraty_sait.py … --media media/
```

На штучному місті: 11 місць → 11 візуалів (по 10 картинок і PDF) → 11 сторінок з «Для медіа». Візуал рахує все в колі
(250–500 м за типом), а сторінка — лише події з назвою самого місця; під блоком це пояснено одним реченням.

## 3. Порівняння (MV-98)

«Тут N · типова станція метро M», де M — середина серед місць того самого типу в даних; кроки однакової ваги, жодного
кольору «гірше»; над таблицею — «Подія — один випадок із рішення суду». Правило мітки — те саме, що в довідці
(`dani-edrsr/src/zvit/analityka.mitka_shkaly`), без бібліотеки scipy; тест звіряє обидва на 360 парах чисел. Місць типу менше
трьох — «замало, щоб порівнювати».

## 4. Житлового нічого

Тест: на жодній сторінці місця немає посилань на будинки, номерів будинків, заборонених слів, «ОСОБА_», описів подій і
посилань на рішення. Підписи з номером будинку («вул. X, 5»), зупинки й знеособлені назви сторінок не мають.
