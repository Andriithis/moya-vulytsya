## 1. Як іде лист

1. **Дані тижня** (сервер, раз на тиждень після оновлення 1551 і випуску): `dani-edrsr/src/nove_tyzhnia.py` →
   `nove-<дата>.json` — одна стрічка на всіх: нові в даних події (різниця з попереднім випуском), звернення 1551 з датою
   тижня по будинках і темах, проблеми. Перекази ШІ для нових подій — `perekazy_istorii.py --podii` (як для історій вулиць).
2. **Лист кожному** (`lyst/lyst.py`): з тієї стрічки — лише те, що в радіусі 300 м від **його** адрес «Стежу».
3. **Канали** (`lyst/lyst_kanaly.py`): пошта, Telegram, сповіщення застосунку (канал готовий у коді, але сповіщення в застосунку вимкнено до окремого рішення — MV-173, ZAVDANNYA-161). Кожен текст перед надсиланням проходить
   перевірку слів (без «небезпечно», рейтингів, прогнозів, порад, службових слів, «ОСОБА», емодзі).

**«Тихий тиждень» — порада: так, для підписки.** Людина платить щомісяця; тиша без листа схожа на зламаний сервіс, а
короткий лист нагадує, що стеження працює. Безкоштовним — нічого (не набридати). Перемикач `tykhyi` — у кабінеті.

## 3. Канали

- **Пошта** — змінна `MV_POSHTA_SERVIS`; зараз лише `zahlushka` (лист `.eml` у теку). Сервіс обирає й заводить партнер; для
  нього дописується один клас з `nadislaty(лист)`. У листі — текст і HTML (світла тема сайту, IBM Plex Sans, кнопка-клавіша),
  заголовки відписки в один дотик (`List-Unsubscribe`, `List-Unsubscribe-Post` — так вимагають Gmail і Yahoo для розсилок).
  Жодних «пікселів» стеження відкриттів.
- **Telegram** — бот «Мій будинок» (`MV_TELEGRAM_TOKEN`): підписнику — повна версія з кнопками «Відкрити «Стежу»» і «Не
  надсилати в Telegram»; безкоштовно — лише числа з кнопками «Підписка — 399» і «Не стежити» (MV-124).
  Записи стеження бота — `--bot-baza` (той самий файл, що в `bot/stezhennia.py`).
- **Застосунок** — лише вміст сповіщення (числа, вулиця без номера: його видно на заблокованому екрані); стик —
  `docs/ANDROID.md`, розд. 6.

Запуск (на сервері): `python lyst/lyst_kanaly.py --strichka nove-<дата>.json --baza lyst.db --bot-baza stezhennia.db
--indeks indeks.json --teka проба/` (ключ відписки — `MV_LYST_SEKRET`).

## 4. Що зберігаємо, відписка

- **Мінімум:** номер підписника (випадковий, не пошта), пошта, номер чату Telegram (якщо під'єднав), тариф, які канали
  ввімкнено, «тихий тиждень» так/ні, коли почали й коли надіслано востаннє; адреси «Стежу» (позначка, адреса, точка).
  Імені, телефону, текстів листів, відкриттів і переходів — ні.
- **Відписка в один дотик:** посилання з підписом (HMAC від номера й каналу, ключ `MV_LYST_SEKRET` лише на сервері). Без
  правильного підпису нічого не вимикається; чужий не відпише чужого. Вимкнено всі канали — записи для листа видаляються.
  Обліковий запис і оплату відписка від листа не чіпає (вони — у сервері продажу).
- **Стик із сервером продажу (ZAVDANNYA-99, ще не злито):** клас `lyst/lyst_skhovyshche.Skhovyshche` — SQLite-заглушка з
  методами `pidpysnyky`, `vymknuty`, `nadislano`, `vydalyty`. Сервер дасть той самий набір методів над своєю базою.
- Посилання відписки з тіла листа відкриває сторінку, яка вимикає листи сама (запитом POST зі скрипту сторінки), — щоб
  поштові сканери, які відкривають посилання, не відписували людей. Сторінку зробить сервер продажу; обробник — `vidpyska()`.

## 5. Що не перевірено

- Жоден лист і жодне повідомлення не надіслано: пошти, токена й ключа немає. Як лист виглядає в Gmail, Outlook, Apple Mail —
  не перевірено (знімки — браузер).
- Числа без порівняння «тут · у сусідів» (`KOMPAS`, розд. 1): у стрічці лише цей тиждень. Порівняння зі «звичайним тижнем»
  потребує історії тижнів — окремий крок.
- «Нове в даних» для подій буває лише тоді, коли виходить новий випуск; між випусками в листі лише скарги 1551.
- На пробному випуску 08.11 стрічку зібрано (тиждень 05–11.10.2026: 316 нових подій за датою рішення, 18 417 звернень 1551
  у 5 093 будинках) — числа лише для перевірки, що працює; переказів ШІ ще немає (у хмарі не викликали).
