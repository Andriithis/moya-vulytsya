# Голос роликів: запис Андрія → чоловічий або жіночий голос (ZAVDANNYA-148, MV-156)

Андрій начитує сам; конвеєр робить з запису голос, якого немає в живої людини, — один чоловічий і один жіночий.
Як записувати — [`YAK-ZAPYSUVATY.md`](YAK-ZAPYSUVATY.md). Чому саме так і ліцензії — [`DOSLIDZHENNYA.md`](DOSLIDZHENNYA.md).

## Порада

**Беремо kNN-VC** (MIT) з голосами-сумішами з українського набору «Голос Америки» (CC BY 4.0). Причини (виміри нижче):
- на чистому записі текст розпізнається так само, як в оригіналі, а система розпізнавання мовця вважає результат **іншою
  людиною** (схожість 0,20–0,41; та сама людина — 0,68–0,85, різні чоловіки — 0,07–0,57);
- голос стабільний від репліки до репліки (схожість реплік між собою 0,74 — як у однієї людини);
- кожні 20 мс виходу взято з чужих голосів — обернути назад, як зсув висоти, нема чого;
- без відеокарти: ≈ 4 с звуку за 1 с на 4 ядрах процесора, без навчання.

**Запасний варіант — RVC (MIT), навчений на тій самій суміші**, якщо на слух kNN-VC звучатиме «металево» (на реальному голосі
Андрія ще не слухали). RVC звучить природніше, але голос треба навчити: десятки хвилин безкоштовного Google Colab (за відгуками спільноти, не перевірено) (клітинками,
без вебінтерфейсу — так дозволяють правила Colab). Готового скрипту навчання тут немає — окреме завдання, якщо знадобиться.
OpenVoice V2 у конвеєрі є (`--rushii openvoice`), але **для чоловічого голосу не годиться**: схожість з вихідним 0,51–0,63 —
межа «та сама людина». Жіночий у нього прийнятний, проте гірше розбірливий за kNN-VC на записі з луною.

Позначка «Голос згенеровано» (MV-150): голос змінено машиною — позначку, найпевніше, лишити; рішення за центральним чатом.

## Як запустити

```bash
python -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r video/holos/vymohy.txt
python video/holos/holos.py pidhotuvaty                       # раз: ≈ 7 хв, 1,6 ГБ у ~/.cache/mv-holos (MV_HOLOS_MODELI)
python video/holos/holos.py peretvoryty zapysy/ --teksty zapysy/teksty.tsv   # → video/vyhid/holos/{cholovichyi,zhinochyi}/*.wav
MV_HOLOS=teka MV_HOLOS_TEKA=video/vyhid/holos/teka-cholovichyi python video/vau/rushii.py <сценарій.json>   # ролик з цим голосом
python video/holos/otsinka.py --pochatkovi zapysy/ --pisla video/vyhid/holos/cholovichyi --teksty zapysy/teksty.tsv  # виміри
```

`video/vyhid/` — не в git. `chysti/` — очищений запис без перетворення (щоб почути, що зробило саме очищення).

## Виміри на тестовому записі (19.11.2026)

Замість Андрія — синтезований голос Piper `mykyta` (три репліки). «Кімната» — той самий голос, зіпсований як запис телефоном:
луна кімнати, шум, гул 50 Гц, стиснення m4a/ogg. Схожість — з чистим вихідним голосом (система розпізнавання мовця ECAPA);
помилки — частка неправильних літер у тексті, розпізнаному Whisper (у вихідного голосу — 0,00–0,12: «сьомою і десятою» Whisper
пише цифрами).

| Що | Схожість з вихідним | Помилки в літерах | Висота, Гц |
|---|---|---|---|
| Вихідний голос, інша фраза (та сама людина) | 0,72–0,84 | — | 119–142 |
| Інша людина (Piper `tetiana`, `lada`) | 0,12–0,20 | — | 197–332 |
| kNN-VC, чоловічий, чистий запис | **0,20–0,41** | 0,00–0,13 | 139–156 |
| kNN-VC, жіночий, чистий запис | **0,24–0,32** | 0,00–0,13 | 203–211 |
| kNN-VC, чоловічий, «кімната» | 0,22–0,41 | 0,06–0,25 | 117–153 |
| kNN-VC, жіночий, «кімната» | 0,19–0,33 | 0,03–0,28 | 200–219 |
| OpenVoice, чоловічий, чистий запис | 0,51–0,63 | 0,00–0,13 | 131–149 |
| OpenVoice, жіночий, чистий запис | 0,31–0,36 | 0,00–0,13 | 215–246 |
| OpenVoice, чоловічий / жіночий, «кімната» | 0,31–0,45 / 0,24–0,26 | 0,11–0,40 / 0,03–0,31 | 126–256 |

Межі для довідки: однієї людини в різних фразах (5 чоловіків і 5 жінок LibriTTS-R) — 0,68–0,85; різних чоловіків —
0,07–0,57 (у середньому 0,26), різних жінок — 0,07–0,46.

Висновки: (1) запис з луною — головна причина помилок, тому інструкція запису важливіша за налаштування; (2) очищення має бути
м'яким: сильне шумозаглушення на тесті знижувало схожість очищеного запису з чистим з 0,80 до 0,55 і додавало помилок.

## Як вибирали

| Спробували | Що вийшло |
|---|---|
| Суміш 5 англійських дикторів LibriTTS-R | чоловічий 0,44–0,47 схожості з вихідним (запис «кімната»); гірша вимова українських звуків |
| Англійська + українська суміш | чоловічий 0,48 на чистому — гірше, ніж лише українська |
| Лише українська суміш («Голос Америки», по 12 хв) | чоловічий 0,32, жіночий 0,29 у середньому — **взяли** |
| 4, 8, 16 найближчих кадрів | різниця в межах похибки; лишили 4, як у авторів kNN-VC |
| «Зсув» ознак до середнього цільового голосу | не допоміг |
| OpenVoice, сила перетворення 0,3 / 0,6 / 0,9 | без помітної різниці; чоловічий лишається схожим |

## Чого не перевірено

- **Справжній голос Андрія.** Тест — на синтезованому голосі; живий голос з телефона може дати інші числа. Першим ділом —
  прогнати 2–3 його репліки й `otsinka.py`.
- **Слухом.** Усе вище — виміри машиною. Чи звучить природно і чи не впізнає Андрія знайома людина — може сказати лише людина.
  Ритм, паузи й слова перетворення не міняє.
- Умови навчальних даних WavLM (GigaSpeech) для похідних моделей — не перевірено (`DOSLIDZHENNYA.md`).
- Колаб для RVC — лише за правилами Colab, саме навчання не пробували.
- Копія набору у форматі opus (`speech-uk/voa-opus`), з якої качаємо, власної позначки ліцензії не має; ліцензія CC BY 4.0 —
  з картки основного набору `speech-uk/voice-of-america` того самого автора (ті самі 326 174 записи, 391 год).
