# db — база даних

**Що тут буде:** опис таблиць і скрипти, які їх створюють (міграції).

**Статус:** порожньо. Етап 2 дорожньої карти, після вибору технологій.

## Що вже вирішено

Сутності та обов'язкові поля зафіксовані в
[`../docs/05-model-danykh.md`](../docs/05-model-danykh.md) і від вибору бази
не залежать.

```
ДОКУМЕНТ → СПРАВА → ПОДІЯ → ЛОКАЦІЯ → ІСТОРІЯ
                     СИГНАЛ → ГІПОТЕЗА
```

## Три обмеження, які мають бути в самій базі

Це не рекомендації, а те, що має бути неможливо порушити:

1. **Подія без посилання на рішення не зберігається.**
   Технічна реалізація правила «факт має джерело».
2. **Сигнал без бази порівняння, періоду, території й кількості подій не
   зберігається.** Технічна реалізація правила «сигнал завжди пояснений».
3. **Гіпотеза не має полів координат узагалі.** Тому фізично не може
   потрапити на карту.

Причина: редакційне правило колись порушать. Обмеження в базі — ні.

## Що ще має бути

- `takedown_request` — журнал звернень про видалення (10-денний строк за законом)
- `pipeline_run` — метрики кожного запуску конвєєра
- `coverage` — покриття по території й періоду
